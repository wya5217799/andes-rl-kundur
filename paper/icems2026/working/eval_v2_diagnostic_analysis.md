# ICEMS 评估结论与根因诊断

日期：2026-07-31

性质：Research Supervisor 诊断报告；非权威实验 feed，不替代 R280、R291 或当前 claim ledger

范围：ICEMS 2026 论文线、EVAL-v2 结果、早期论文探针与 11 轴评估、R270 以来的物理机制研究

## 1. 总结论

这次统一评估是必要的，而且确实比只看训练 reward 或单次论文指标更容易找到问题。但当前结果必须拆成两个结论：

1. **EVAL-v2 的性能统计有诊断价值；旧版顶层 `INVALID` 判定错误，schema 2 已完成纠正。**

   旧脚本以固定 `1e-9` 容差复现了已经被 R280/CLM-0610 纠正的 R279 判定。schema 2 改为不可覆盖的 one-float32-ULP 规则，192 条轨迹的输入完整性与执行契约均通过。它同时删除了脚本自授的 `evidence_eligible`，明确把论文证据资格交还 claim/feed/verdict ledger。

2. **纠正有效性之后，评估结果强化了最初的物理判断，而不是推翻它。**

   学习控制器对区域间差模同步有真实作用，但对共同频率恢复几乎没有作用；慢速有功层负责持续恢复，固定 3 s 共同惯量脉冲负责早期瞬态，学习到的 \(q[1,1,-1,-1]\) 只负责差模整形。

3. **共享控制器的主要问题不是笼统的“TD3 不够先进”，而是动作表示与聚合结构。**

   四个局部输出被秩一投影压成一个 \(q\)。现有轨迹显示，共享策略经常让四个原始输出同号饱和，随后被零和投影抵消；这种现象在负向扰动尤其严重，并且与共享策略的符号不对称和种子差异一致。

4. **R291 已经否定“只要把固定 3 s 改成状态触发就能解决”的简单解释。**

   同一共同 \(M\) 动作的状态感知交接没有通过联合门槛。因此，当前问题不能再简化成“缺一个更聪明的 gate”；更可能的方向是动作坐标不足、共享表示浪费、以及差模阻尼/快速有功等尚未验证的物理执行通道。

5. **对 ICEMS 论文，不需要再开启新的控制实验。**

   当前应修复评估器、收紧论文表述、公开负结果与边界。对后续期刊线，只有在新的前瞻性问题和执行器 authority gate 建立后，才值得继续 D、快速有功、向量局部动作和拓扑泛化。

综合判定：

| 对象 | 判定 |
|---|---|
| EVAL-v2 schema 2 诊断有效性 | **PASS：192/192 输入完整、执行契约零违规** |
| R280 已封存的核心性能结论 | **PASS：仍然有效** |
| 当前多智能体增量价值主张 | **不成立，必须删除或改成受限 factorization 结果** |
| 固定 Kundur 两区域机制研究 | **有研究价值，适合作为受限会议论文** |
| 拓扑泛化、广义 MARL、稳定性与部署主张 | **未测试** |
| 为 ICEMS 再做一轮控制实验 | **当前不需要** |
| 后续期刊研究 | **有条件需要，先过物理执行器与信息价值门槛** |

## 2. 三套评估应该怎样定位

### 2.1 原论文探针

EVAL-v2 已验证：

\[
\text{paper\_cum\_rf\_sum}
=-T N\cdot \text{normalized\_sync\_loss}.
\]

它与归一化同步损失在同一条轨迹上是精确变换，不是第二个独立证据。它只衡量各 VSG 相对共同频率的离散程度，不能证明共同频率恢复。以后可以保留为论文兼容性检查，但没有必要把它当成独立测试重复解释。

### 2.2 历史 11 轴评估

11 轴评估对调试曾经有价值，因为它暴露过：

- agent 不活动；
- 晚期振荡；
- 功率分配失衡；
- 动作利用率过低；
- 与论文图形锚点的差距。

但它不适合作为最终客观排名器：

- 早期 7 轴分解曾显示，平滑度与动作范围等多个轴对成功控制器几乎恒为 1，settling 对所有控制器又几乎恒为 0；真正区分控制器的主要是峰值和终值两个轴。
- v2 把退化的 range-in-box 改成 action utilization；v3.0 增加三个 gate；v3.1 又因排序与直觉冲突而改变聚合公式。
- 阈值部分来自论文图形目测与工程判断，并且把物理性能、动作风格和启发式 gate 压成一个几何均值/最小值复合分数。

这说明 11 轴应该是**诊断面板**，不能是“谁最好”的单一证据。

### 2.3 EVAL-v2

EVAL-v2 的正确进步包括：

- 使用 60 Hz 物理频率；
- 分开共同模与差模；
- 同时看快窗、全窗和 3--10 s 次生窗口；
- 使用配对比较与种子/场景两层 bootstrap；
- 保留尾部风险、动作、储能约束和失败；
- 禁止复合总分与总排名；
- 明确旧论文探针只是兼容性指标。

因此，未来应以 EVAL-v2 的结构为主、旧探针为兼容项、11 轴为可选诊断项。但 EVAL-v2 本身必须先与当前正式证据规则同步。

## 3. 有效性审计：首先发现的是评估器问题

旧版 scorecard 报告：

- 192/192 条轨迹与 sidecar hash 完整；
- 物理频率基准正确；
- 配对矩阵完整；
- 仅有五个 `q_slew` 检查失败；
- 因此把整体标为 `INVALID`。

这个结论与当前权威证据冲突。CLM-0610/R280 已证明：

- 最大表观超限为 \(7.450580596923828\times 10^{-9}\)；
- 它小于 \(0.25\) 处的一个 float32 ULP，
  \(2.98023223876953125\times 10^{-8}\)；
- 五项均由 false 改为 true；
- 没有轨迹、checkpoint、bootstrap 样本、效应量或性能门槛发生变化；
- 当前分类是 `CENTRALIZED-EXPLANATION-SUFFICIENT`。

因此这里的根因是**评估契约漂移**：脚本硬编码了旧的数值容差，却没有读取 R280 的表示感知规则与 supersession 状态。

因此这里的根因是**评估契约漂移**：旧脚本硬编码了数值容差，也把诊断输入有效性与论文证据资格混为一个布尔值。

schema 2 已完成四项工程修正：

1. 用正式且不可覆盖的 one-float32-ULP 规则替代默认 `1e-9`；
2. 将 `input_integrity`、`execution_contract` 和外部 `evidence_status` 分离；
3. 不再由事后脚本声明证据资格，而是返回 `EXTERNAL_AUTHORITY_REQUIRED`；
4. 将自身 bootstrap 与投影/分层统计明确标为诊断性重算；论文共同主指标仍引用 R280 已封存区间。

对原 192 条轨迹的 schema 2 复跑结果为：

- `validity.diagnostic_pass=true`；
- sidecar hash `192/192` 验证通过；
- execution violation `0`；
- family effect 的全部点估计与修复前逐项完全一致；
- JSON SHA-256 为 `b1051d84ef58318bcdddaa6cf7b1924df21adff2a22795fae89d7660b72c72c2`；
- Markdown SHA-256 为 `3fe03825fe92a39f358e569298b6fd711c840a249346f8fa47a711cc897263dc`。

这只证明当前不可变轨迹可用于事后诊断，不把 schema 2 的重算区间升级成正式论文证据。

## 4. 当前正式结论：学习确实有用，但作用范围很窄

R280 是当前正式证据：

| 正式共同主指标 | Centralized TD3 vs \(q=0\) | Shared TD3 vs \(q=0\) | Shared vs Centralized |
|---|---:|---:|---:|
| 同步损失 | -24.345456% [-31.500633%, -17.481533%] | -16.793845% [-24.73%, -5.81%] | +9.981702% [+1.04%, +26.13%] |
| 前 3 s 区域间 IAE | -17.040674% [-24.595353%, -8.959552%] | -9.540768% [-17.19%, -0.60%] | +9.040461% [+3.09%, +19.54%] |

这支持三个受限结论：

1. \(q[1,1,-1,-1]\) 这个差模动作坐标存在可学习的真实余量；
2. 当前共享局部 actor 加输出聚合的 factorization 有效，但弱于直接输出同一标量 \(q\) 的集中式 actor；
3. 结果不能证明“集中式 AI 优于所有 MARL”，更不能证明“AI 优于经典差模控制”。

EVAL-v2 的事后次指标进一步显示：

- Centralized 对全窗区域间 IAE 改善约 14.59%，对 3--10 s 区域间 RMS 改善约 14.03%；
- Shared 对全窗区域间 IAE 仅改善约 4.52%，对 3--10 s 区域间 RMS 约为 0；
- 两种学习控制器的 VSG 共同频率全窗 IAE 反而微弱增加约 0.05%，前三秒共同频率 IAE 增加约 1.7%--1.8%；
- 所有学习 \(q\) 在 3 s 后严格回零。

这些次指标是事后诊断，不是新增正式 claim；但它们清楚说明：集中式策略在快窗内形成了能延续到后窗的差模轨迹改善，共同频率恢复却没有来自 \(q\)。

## 5. 新发现的算法根因：秩一投影中的输出抵消

共享控制器的执行映射为：

\[
q=\frac{q_{\max}}{2}
\left(\operatorname{mean}(z_1,z_2)
-\operatorname{mean}(z_3,z_4)\right),
\qquad
\Delta M=q[1,1,-1,-1].
\]

从四个原始输出 \(z\) 到一个 \(q\) 是秩一映射，存在三维零空间。共同分量 \([1,1,1,1]\) 和区域内不一致分量不会被电力系统执行。集中式 actor 直接输出 \(q\)，没有这个原始动作零空间。

对现有 192 条不可变轨迹做事后分层诊断，定义：

- 四个 \(|z_i|>0.9\) 且同号；
- 同时 \(|q|<0.025=0.1q_{\max}\)；
- 只统计前 15 个活动步。

得到：

| Shared 轨迹分组 | “同号饱和但投影后近零”步数占比 |
|---|---:|
| 全部三个种子 | 24.44% |
| 负向扰动 | 46.85% |
| 正向扰动 | 2.04% |
| seed 17 | 38.89% |
| seed 53 | 32.22% |
| seed 89 | 2.22% |

三个共享种子的该比例与性能呈一致的单调关系：

| Shared seed | 抵消率 | 同步损失 vs \(q=0\) | 前 3 s 区域间 IAE vs \(q=0\) |
|---|---:|---:|---:|
| 17 | 38.89% | -11.104% | -5.926% |
| 53 | 32.22% | -16.763% | -8.962% |
| 89 | 2.22% | -22.514% | -13.735% |

这些抵消率与场景分层数字现已由 EVAL-v2 schema 2 从不可变轨迹机器生成，并进入带 SHA-256 的 JSON/Markdown scorecard。其角色仍是 `exploratory_post_hoc`：可以确定工程排查优先级，但不能替代 R280，也不得被写成投影抵消导致性能差异的因果 claim。

这里只能作诊断关联，不能把三个种子当成充分的因果证明。但它已经把“共享策略平均较差”缩小成一个可观察的执行机制：

> 共享局部 actor 经常把很大的动作输出到投影零空间，尤其在负向扰动和 seed 17/53；集中式 actor 则把容量直接用于可执行的差模坐标。

进一步的场景分解也支持这一点：

- 负向扰动中，Centralized 的同步损失相对 \(q=0\) 改善约 20.02%，Shared 仅约 0.78%；Shared 的前 3 s 区域间 IAE、全窗区域间 IAE 和 3--10 s 区域间 RMS 分别恶化约 4.52%、12.97% 和 20.38%。
- 正向扰动中，两者的同步损失改善接近，Centralized 约 26.70%，Shared 约 25.52%。
- Centralized 与 Shared 的主要差距集中在 `PQ_0`、`PQ_1` 扰动；在 bus 14/15 的前 3 s 区域间 IAE 上，两者接近。

因此，共享策略不是均匀地“能力较弱”，而是具有明显的**符号、位置和种子条件化失效**。最值得检查的是局部观测的符号/区域可辨识性、参数共享造成的同向输出、以及投影零空间缺少约束。

## 6. 与最初研究分析的闭环

R270 的初始物理判断是：

- 更多 TD3/SAC/LSTM 不能创造共同模控制 authority；
- \(M/D\) 对同步、RoCoF 和峰值有真实快瞬态作用；
- 该 authority 是模态特定的，不能把同步改善写成频率恢复；
- 必须增加明确的有功/二次频率执行器，形成快慢分层架构。

后续证据逐步闭环：

1. **R274：**慢速 BESS 有功 droop--PI 对共同频率恢复有强 authority；
2. **R275：**固定 3 s 共同惯量脉冲对四个快指标有增量价值；
3. **R276：**快慢两层是加性的，没有证据支持“协同增益”；
4. **R277：**差模 \(q\) 存在 outcome-seeing 上界余量；
5. **R280：**Centralized 与 Shared 都能利用该余量，但 Shared 较弱；
6. **R291：**同一共同 \(M\) 动作的状态感知平滑交接没有联合价值。

因此，当前最合理的根因层级是：

| 层级 | 根因/问题 | 证据强度 | 当前动作 |
|---|---|---|---|
| 评估层 | 旧 EVAL-v2 未同步 R280 表示规则 | 已证实且已修复 | 保持 schema 2 回归测试与外部证据边界 |
| 物理层 | 差模惯量不能替代共同有功恢复 | 已证实 | 论文明确快慢与共同/差模职责 |
| 架构层 | 四个共享输出经秩一投影产生零空间浪费 | 强诊断证据 | 加入投影效率与抵消率面板 |
| 泛化层 | Shared 对符号、位置、种子高度不均匀 | 已观察，原因未唯一识别 | 检查观测对称性与训练分布 |
| 交接层 | 简单状态 gate 不是当前修复方案 | 已证实但范围受限 | ICEMS 保留固定 3 s |
| 机制层 | \(q\) 是否改变目标模态阻尼尚无小信号因果证明 | 未证实 | 只能写 time-domain association/intervention |
| 拓扑层 | 单一修改 Kundur 拓扑不能支撑拓扑泛化 | 未测试 | 不启动 GNN 主张 |

## 7. 整体设计评价

### 7.1 做得好的部分

- 已经从“搜索更强 AI”转向“先证明执行器 authority”；
- 将共同模恢复、共同快支撑和区域间差模整形分层；
- 使用 ANDES 真实时域仿真而不是代理环境自证；
- 采用独立扰动库、配对统计、保留失败、动作/储能 guard 和正式 supersession；
- Centralized 与 Shared 输出同一个 \(q\)，使架构比较比早期异构算法排名更可解释；
- R291 的负结果阻止了在相同动作坐标上继续无边界地训练 gate 或 MPC。

### 7.2 仍然限制论文强度的部分

- plant 是 PV+GENCLS VSG proxy 与独立 ESD1，并非统一 GFM-BESS；
- 学习动作只有一个差模惯量标量，\(D=0\)，不是一般的多设备 \(M/D/P\) 协同；
- Shared 同时改变了信息模式和输出 factorization，现有对比不能唯一分离“局部观测不足”“聚合抵消”和“优化问题”；
- 固定拓扑、三训练种子、全状态仿真、无通信故障；
- 没有小信号模态、Lyapunov/耗散或 EMT/HIL 证据；
- 固定因果 comparator 的动作量远低于学习策略，其失败不能代表经典差模控制器这一类别。

所以当前设计作为**受限的两区域差模协调与架构对照会议论文**是合理的；作为“MARL 拓扑泛化控制方法”则不够。

## 8. 怎样优化评估，才能更好地找到问题

### 8.1 schema 2 已纳入、无需新 ANDES 仿真的诊断

1. **投影效率**
   \[
   \eta_{\mathrm{proj}}
   =\frac{|q|/q_{\max}}{\operatorname{mean}|z_i|+\epsilon}.
   \]
   同时报告零空间能量、同号饱和抵消率和区域内 vote dispersion。

2. **符号/位置/强度分层**
   对 location、sign、severity 分别报告 family effect、场景胜率和最坏两例，不能只看总体均值。

3. **种子级执行机制**
   把每个训练种子的性能、\(q\) L1、TV、边界驻留时间、投影效率并列，避免“平均后看不见策略塌缩”。

4. **动作—结果关联**
   在每个场景内分析 \(q\) 的符号、切换、峰值时间与区域间频差的相位关系；只作为机制线索，不写成模态因果结论。

5. **指标分级**
   明确标注：
   - formal co-primary；
   - validity/safety guard；
   - exploratory diagnostic；
   - legacy compatibility。

6. **旧探针去重**
   原论文探针只做恒等式校验；11 轴不再输出唯一 winner，可保留逐轴异常标志。

实现状态：1、2、3、5、6 已由 schema 2 结构化输出；第 4 项目前只完成动作强度、切换/总变差、投影与结果的同场景并列，尚未做相位或峰值时序的因果识别。因此当前只能称“可复现机制线索”，不能称模态机制证明。

### 8.2 若未来重新打开算法研究

必须另立问题、重新封存，优先级应是：

1. 对共享输出增加投影零空间正则或直接重参数化，使 actor 输出可执行的 area-signed amplitude，而不是允许四个 raw vote 在三维零空间漂移；
2. 用等变的区域符号/身份编码检查正负扰动对称性；
3. 用 matched action budget 区分“集中式信息优势”和“只是执行了更多 \(q\)”；
4. 若要主张真正多智能体价值，改为可归因的 per-device 向量动作，并设置集中式、参数共享、无通信和经典分布式基线；
5. 在任何新学习之前，按 same-\(M\) constrained oracle → 有界 \(D\) → 必要时快速有功 \(P_{\mathrm{fast}}\) 的顺序证明新增执行坐标有余量；
6. 只有 topology information-value gate 先通过，才进入 GNN 或拓扑泛化训练。

这些都是未来期刊线的候选路线，不是当前 ICEMS 的补实验清单。

## 9. ICEMS 论文应怎样修改

### 可以写

- 慢速有功层提供持续共同频率恢复；
- 固定共同惯量脉冲提供受限早期瞬态增益；
- 一个零和差模惯量坐标存在可学习余量；
- 在相同标量 \(q\) 下，当前 Shared factorization 有效但弱于 matched Centralized；
- 状态感知共同 \(M\) handoff 的受限负结果；
- 结果只适用于当前修改 Kundur/ANDES 设置。

### 不可以写

- MARL 作为类别优于 centralized 或 classical control；
- 学习 \(q\) 实现了共同频率恢复；
- 当前结构实现了严格动态解耦；
- 3 s 是最优 handoff；
- 已证明拓扑泛化、稳定性、安全性或部署可行；
- 当前 EVAL-v2 的 `INVALID` 是正式证据状态。

建议将论文主线收敛为：

> 在已验证慢速共同频率恢复与固定快支撑的基础上，研究一个受限零和差模惯量坐标；独立评估显示学习策略能利用该余量，但参数共享局部输出聚合并未带来相对集中式 actor 的优势，并呈现可诊断的投影抵消与场景不对称。

这条主线比“更强 MARL 算法”更真实，也更容易通过审稿人的物理与证据审查。

## 10. 最终研究决策

当前最重要的不是再训练一个 Agent。前两项已经完成，剩余工作顺序为：

1. **已完成：**修复 EVAL-v2 的有效性/证据状态；
2. **已完成：**把投影抵消、符号不对称和种子差异加入诊断报告；
3. 以 R280/R291 为权威边界修改 ICEMS 文字；
4. 停止 ICEMS 线上的新控制实验；
5. 未来只有在新的物理执行坐标或拓扑信息价值通过前瞻性 gate 后，才重新进入算法训练。

因此，研究问题本身有必要，但必要性来自**物理职责分解、可执行动作表示和可证伪的架构比较**，不是来自继续堆叠 AI 算法。
