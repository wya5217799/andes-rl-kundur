# Hybrid control literature note: what should learning own?

**Question.** In 2022--2026 primary power-systems/control literature, is pure end-to-end reinforcement learning (RL) a defensible default for inverter/VSG/BESS control, or is the stronger direction model-based/classical control plus safe, residual, or physics-informed learning?

**Scope.** Bounded search through 2026-08-03. The 12 sources below are primary papers, standards, or official technical specifications closest to fast inverter/VSG/BESS control, distributed coordination, constraints, and learning. This is a directional synthesis, not a systematic-review count. Here, *default* means the architecture that should carry the burden of proof in a paper-facing controller design, not whether model-free RL papers can still be published.

## Bottom line

**Pure end-to-end RL is not the defensible default.** It remains an active empirical research arm, including genuinely decentralized CTDE/MARL, but the stronger and more auditable 2022--2026 direction is:

1. an implementation-faithful plant/reduction and a structured classical controller;
2. explicit current, power, ramp, energy/SOC, ride-through, and information constraints;
3. analytical guarantees restricted to the model and operating set for which they are actually derived; and
4. learning used only where a measured gap remains--for structured gain learning, constrained output feedback, an explicit residual, or an offline approximation of a safe optimizer.

This is not a theorem that hybrid learning always outperforms end-to-end RL. It is an evidence-and-assurance judgment: standards are performance-based and method-neutral, while the most credible control papers expose the physical structure and proof domain; the end-to-end MARL example below supplies simulation evidence, not a closed-loop safety or stability theorem.

## Consequences for the model-first MARL paper

1. **Keep the deterministic gates.** The current sequence--DAE fidelity, exact invertible common/differential coordinates with retained cross blocks, actuator authority, constrained distributed control, then a prospective residual-headroom test--is aligned with the strongest literature pattern.
2. **Do not make “RL versus classical control” the research question.** The defensible question is whether a neighbour-local learned residual adds paired value over the strongest feasible distributed physics controller under the same vector action, information graph, limits, bank, and budget.
3. **Use learning only for a named unresolved residual.** A safe architecture is `distributed controller + fleet-neutral edge residual + action governor/successor-set check`. If the deterministic controller closes the registered gap, neural training should remain a prospective NO-GO.
4. **Separate proof from experiment.** Candidate proof obligations are DAE reduction regularity, transform invertibility, neutrality/headroom preservation, and conditional feasibility/safety inheritance. Performance superiority, topology transfer, and neural incremental value remain empirical and require held-out evaluation.
5. **Keep the claim ceiling narrow.** Even a positive result would support “bounded neighbour-decentralized residual value on the declared phasor-domain plant,” not universal MARL superiority, hard decoupling, GFM-BESS deployment, or IEEE-2800 compliance.

**Decision:** proceed model-first. Pure end-to-end MARL may remain a matched ablation/reference, but it should not be the proposed controller or the source of safety. Start neural training only if the frozen deterministic and residual-headroom gates leave a nonzero, physically actionable, independently executable gap.
