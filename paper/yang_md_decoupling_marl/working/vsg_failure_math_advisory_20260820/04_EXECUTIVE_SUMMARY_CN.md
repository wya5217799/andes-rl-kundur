# 并联 VSG 多智能体强化学习失效数学顾问报告：中文执行摘要

## 结论

当前证据包足以形成三项会议论文窗口内的**有界数学贡献**，但不足以支持“稳定裕度已识别”“所有控制器均不可行”或“某一训练故障已经被因果证明”等强结论。

P1 的可发表结果是精确的比值灵敏度分解：注册端点 $r_d=E_K/E_L$ 的变化由候选控制器能量项与本地参考能量项共同决定。封存数据表明，relaxed block 的失败本质上是“相对本块参考的改善不足”；由于三个 R415 block 使用的扰动/探测身份不匹配，且没有复环路响应，不能把差异解释为 $M/D$ 的有限差分，也不能反推出增益裕度或相位裕度。R437 只是否定了已注册的频带失谐解释，不能替代环路裕度测量。

P2 的可发表结果是纯整数延迟的精确灵敏度放大公式。R440 的一拍与两拍延迟都使差模端点越过上限，但对应物理无害守卫仍通过，因此应写成“端点边界失效”，不能写成“稳定性失效”。封存 JSON 未提供同一实验库的零延迟点、采样周期和复环路增益，所以不能给出物理时间单位的解析延迟裕度，也不能证明相位损失是唯一原因。

P3 的可发表结果是 index-1 DAE 消元后的精确输入通道

$$
B_{u,r}=f_u-f_yg_y^{-1}g_u.
$$

在同步、功率平衡平衡点，若 $M/D$ 不直接进入其他微分残差，也不进入代数约束，则摆动方程对 $M/D$ 的直接一阶导数为零，且 $g_u=0$，从而 $B_{u,r}=0$。这是一条条件性引理。证据包没有实际 ANDES DAE Jacobian，因此不能断言实现对象的一阶通道为零或非零。报告给出了“固定 $x$、正负扰动 $u$、每次重新求解代数平衡、中心差分”的最小测量方案，并要求与 Schur 重构独立对照。

## 机制题的可信解释

M3：若带消息策略类严格包含无消息策略类，并且做总体最优求解，增加信息不可能降低最优值。因此 CD-MATD3 中的负消息增量不应解释为“邻居信息本身有害”，而应定位到有限样本、优化、实现非嵌套、分布偏移或奖励/critic 梯度干扰。R438 仅对 adapted-SAC 的差模端点提供“观察通道偏向”证据，尚不能解释非对角端点。

M5：四个封存 winner 的每个分段都使用相同增益，故这些结果不构成“时变调度有益”的证据；它们实际证明的是把候选增益扩展到更大常数后，端点可以继续改善，但已选 winner 的动作 RMS 与总变差同时上升并触发动作守卫。现有记录只保存 winner，不能排除“同样改善但应力更低”的候选仍存在。

M4：残差策略回到恒等映射，只有在正则化目标对零残差的一阶变分为零、二阶变分非正时，才能称为局部最优。封存端点接近基线只描述现象，不能区分真实局部最优、critic 梯度错误、熵/正则化压制、投影抹除或训练停滞。最小实验是沿可行切向方向做正负对称残差探测并保存原始/投影动作和梯度。

M1：对投影对偶更新，乘子已在上限时，当且仅当约束残差非负，下一步仍保持上限。R425/R427 的正残差和上限乘子完全符合这一机械规律。固定步长可以解释“如何到达上限”，但不能在残差已为负时解释“为何仍停在上限”。该现象不是策略类不可行证书。

M2：在零均值 critic 误差假设下，双 critic 取最小值对回报是非正偏差，即悲观偏差；在负成本奖励下等价于高估成本，而不是乐观高估回报。因此“最小值算子导致 common return 乐观”这一通用链条符号不成立。critic 发散仍可能通过非线性函数逼近、离策略自举、移动目标和共享特征破坏训练，但没有理论理由让它只污染 common channel。需要 common/differential head 的真实动作梯度、校准误差和单头稳定化干预才能建立因果性。

## C1：可证明的控制器类证书

严格的不可行结论只能限定在一个精确定义的、稳定的、有界凸类中。推荐做法是在已验证稳定基线周围构造 FIR-Youla 参数 $Q$，或采用满足完整 achievability identity 的 FIR-SLS 响应变量。固定扰动、窗口和正的参考能量后，有限窗口输出可写成 $b+Aq$，差模/非对角能量约束成为二阶锥约束。以公共松弛量 $t$ 构造 phase-I SOCP 后，独立验证的正对偶下界 $\delta>0$ 才能证明“该精确类内无可行控制器”。当前演示求解器明确标记没有 formal dual certificate [C1-S01]，所以现在只能给出程序，不能给出不可行结论。

对非线性 headroom/DAE 映射，线性证书只有在固定 active mode 的验证管形内，或存在统一响应误差界 $\varepsilon$ 时才能转移；若线性下界满足 $\delta>\varepsilon$，才可保留非线性不可行结论。发生限幅/投影模式切换时，必须采用模式枚举、混合整数锥表示、鲁棒余项界或把结论明确限制为局部线性结果。

## 直接用于论文的边界

可直接考虑纳入会议稿的是：P1 的比值灵敏度恒等式及“相对能量失败”表述；P2 的纯延迟恒等式及“端点失效但守卫通过”表述；P3 的 DAE Schur 输入通道与有限差分验证方案。对应英文段落已单独整理在 `report/paper_ready_paragraphs_P1_P3.md`。

不应写入会议稿的强结论包括：relaxed block 已由相位裕度解释；一拍延迟导致不稳定；实现对象的 $B_{u,r}$ 已知为零；消息在一般意义下有害；时变调度已被证明必要；乘子封顶证明策略类不可行；critic 发散已被证明是 common gap 的唯一原因；或所有有限阶/因果/MARL 控制器都不能达到目标。
