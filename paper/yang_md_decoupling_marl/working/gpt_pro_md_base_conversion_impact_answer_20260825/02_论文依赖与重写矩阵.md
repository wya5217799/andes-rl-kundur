# 论文依赖与重写矩阵

## 1. 按内容层分解

| 内容层 | 基值修正后的状态 | 原因 |
|---|---|---|
| 基值/参数卡/运行时边界 | 必须新增或重写 | 历史遥测没有暴露实际运行时减半；论文必须区分 device/system base |
| 算术公共与注册差分坐标定义 | 可保留 | 坐标矩阵不含 `M,D` |
| 端点 `J_cross,J_d` 的定义 | 可保留 | 数学估计量定义不依赖具体轨迹 |
| guard 规则与阈值定义 | 可保留 | 合同形式可复用；历史 pass/fail 不可复用 |
| exact-equilibrium `B_{v,r}=0` | 可保留并重审表述 | 结构零与参数数值无关；不得外推到有限幅值 |
| 线性化矩阵、模态、张量数值 | 必须重算 | `1/M` 刚度和输入通道改变，完整特征结构可变 |
| 全部时间域图、端点表、guard 计数 | 必须替换 | 都来自旧 implemented object |
| deterministic winner 和 holdout | 必须重新选择/验证 | plant 修正对不同控制器不是共同标量 |
| SAC/RMS-SAC | fresh 训练和评估 | 训练核、状态分布和动作分布改变 |
| source factorial | 全 fresh 8 臂训练 | cell 级修正偏移不共同；旧 carryover 不合法 |
| energy-port 正见证 | 高风险，需正式确认或删除 | 两组修正诊断均未过 0.95 |
| residual SAC 无增益 | 条件式 fresh 训练 | 只有论文保留该 claim 时才值得重做 |
| “不是 COI/不是模态”术语边界 | 可保留 | 这是坐标定义事实 |
| coordinate sensitivity 数值 | 离线重算 | 轨迹与修正模态基均改变 |

## 2. 按论文部分映射

### 标题

`Decoupling-Oriented Coordination of Paralleled VSGs With Multi-Agent Reinforcement Learning`

- **可暂时保留**，前提是修正后的 direct `M/D` 仍提供可重复的 decoupling 现象，并且 MARL 部分仍是论文实质组成。
- 若 fresh MARL 被全部删除、或 direct comparator 正式失败，则标题中的 “Multi-Agent Reinforcement Learning” 或 “Decoupling-Oriented Coordination” 可能失真，进入最大重写。

### 摘要

必须删除或占位所有旧数值：60.79%、64.13%、SAC 比值、guard 计数、factorial 效应、能量端口正见证。摘要只能在修正正式证据完成后重写。当前最多可说：

- 已发现并修复 device/system-base 语义错误；
- 结构平衡点结论不变；
- 修正后的 deterministic 小批诊断支持继续研究；
- 论文级结论尚在重验证。

上述最后两点也不应放入投稿稿件，除非明确作为方法/纠错说明而非结果。

### 引言与贡献列表

可保留：

- 公共/差分协调问题；
- guard-first、非 pooled 的评价原则；
- 结构权威与有限时间权威分离的思想。

需条件式重写：

- “MARL 未关闭合同”的贡献；
- “actor/critic source 无 material effect”的贡献；
- “能量端口给出正见证”的平衡叙事。

若能量端口正式失败，应把它改写为一个受约束的负结果、失败案例或删除，而不能继续称 constructive witness。

### Section II：数学定义与评估合同

大部分可保留，但必须增加：

\[
M^{sys}=M^{dev}\frac{S_n}{S_b},
\qquad
D^{sys}=D^{dev}\frac{S_n}{S_b},
\]

并明确：

- controller/action/reward/telemetry 使用 device base；
- simulator runtime 使用 system base；
- 每次边界只转换一次；
- 参数卡是继承的 project calibration，不是严格 Yang 基准；
- 算术公共坐标不是 COI；注册差分坐标不是动态模态。

### Section III：控制器、环境与训练协议

必须重建受影响部分：

- reset 时从实际 runtime 读插值锚点；
- action target 转成 system base 后写入；
- readback 再转回 device base；
- 首个零动作保持性与五子步检查；
- corrected deterministic selection；
- fresh learning/factorial 的 seed、checkpoint 和禁止 carryover 合同。

控制器公式与统计 estimand 可以复用，但所有“实现即公式”的声明都需以新 invariant/readback 支撑。

### Section IV：结果

应视为**全部失效待替换**，包括：

- 每条时间轨迹和图；
- 所有端点、相对降幅和排名；
- 所有 guard pass/fail；
- SAC/RMS-SAC 表格；
- source factorial 主效应、交互、p 值/区间；
- energy-port heldout、拓扑、额外条件和 residual-SAC 结果。

旧结果可在内部 archive 中作为“历史错误对象”保留，但不能与修正银行 pooled，也不能在正文中以脚注方式继续作为物理结果。

### Section V：机制解释与讨论

可保留的核心：

- exact-equilibrium direct `M/D` 一阶零权威；
- 结构结论与有限时间/非线性结论必须分开；
- arithmetic coordinate 与 COI/modal coordinate 的定义差异。

必须重建：

- 数值张量和 finite ladder；
- “为什么学习失败”的任何因果解释；
- direct/energy-port 对照叙事；
- source factor 的机制解释；
- 泛化、安全性和拓扑稳健性论述。

### 结论

只能在修正正式证据结束后写。当前不能预先锁定“MARL 失败、source 不重要、energy port 成功”的旧三段式结论。

## 3. 六类 claim 的依赖 DAG

```text
基值语义正确
├── deterministic direct M/D bank
│   ├── development selection
│   ├── fresh unseen holdout
│   └── coordinate sensitivity / local math
├── energy-port deterministic bank
│   ├── positive witness (currently challenged)
│   ├── topology/extra conditions
│   └── residual SAC (only if claim retained)
└── learning chain (only if deterministic comparator survives)
    ├── projected SAC fresh train/eval
    ├── RMS-SAC fresh train/eval
    └── 8-arm source factorial, all fresh
```

任何下游结论都不能用 invariant pass 代替。`SEMANTIC-GATE-PASS` 只关闭“实现是否遵守卡片”的工程义务，不关闭性能义务。

## 4. 三种重写情景的决策规则

### 情景 A：最低限度可辩护重写

同时满足：

1. corrected deterministic 九法则重新选择后有一个 guard-valid winner；
2. winner 在全新 unseen holdouts 保持与旧叙事相同的定性方向；
3. fresh projected/RMS 仍未关闭完整合同；
4. fresh factorial 四个注册效应不越过 10% materiality；
5. energy-port 正见证正式恢复，或有预先定义、非事后调参的替代正见证；
6. COI/modal sensitivity 不改变 endpoint 排序和主结论。

结果：标题和主叙事可保留，但所有图表与数字替换；这仍是大规模证据替换，不是勘误表。

### 情景 B：中等重写

满足 direct `M/D` 机制仍有意义，但下列任一发生：

- winner、排名、裕度或 guard 模式变化；
- MARL trade-off 或 source-factor 解释变化；
- energy-port 正见证正式失败；
- coordinate sensitivity 必须进入正文并限定旧 decoupling 解释。

结果：Sections III–V、摘要、贡献和结论重建；Section II 与标题可能保留。当前两组能量端口失败诊断和 direct 正向诊断组合最符合这个情景。

### 情景 C：最大重写/新论文

下列任一足以触发：

- 无 corrected direct deterministic comparator 能通过完整合同；
- fresh MARL 反而显著成功，推翻旧 negative-learning 主结论；
- source effect/interaction 成为材料性主结果；
- decoupling 坐标解释对 COI/modal 选择不稳健；
- 正向伴随机制消失，且剩余材料不足以支撑标题和贡献结构。

结果：重新定义研究问题、标题、方法链和贡献；只保留基值治理、guard-first 评估、结构数学和部分坐标工具。

## 5. 当前应采用的编辑策略

在正式证据出现前：

- 把现稿视为“旧 implemented object 的历史文档”，不要直接局部改数；
- 建立 claim ledger，将每个图表/句子标为 `STRUCTURAL / OLD-OBJECT / CORRECTED-ENGINEERING / CORRECTED-DIAGNOSTIC / CORRECTED-FORMAL`；
- 先按中等重写预留版面与贡献结构；
- energy-port 分支优先做“正式确认或主动删除”的二选一，避免为高风险旧 claim 扩大实验；
- direct 正式 comparator 存活前，不开启昂贵 full learning/factorial。
