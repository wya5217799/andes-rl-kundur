# R478 VSG M/D 基值换算错误：数学与论文影响审计

本包是对 `gpt_pro_md_base_conversion_impact_20260825.zip` 的结论型交付。仅包含新撰写的 Markdown 审计材料，不包含用户提供的论文、源代码、原始轨迹、CSV、JSON、日志或其他输入数据。

## 结论

这不是可以在旧结果上统一“乘二/除二”修复的记账错误。历史实现对四台受控 VSG 的运行时 `M,D` 同时少写了一个设备基值到系统基值的因子 2；因此 `D/M` 保持不变，但功率失配项和同步刚度项相对正确对象放大为 2 倍，首个零动作写入还使名义惯量从 400 s 瞬时改写为 200 s。状态本身连续，但向量场、闭环状态转移核、策略所见分布、有限窗能量、阈值判定与训练问题均发生实质变化。

当前证据支持：

- 结构性的“精确平衡点处直接 `M/D` 一阶控制权为零”仍成立；
- 算术公共/注册差分坐标的定义仍成立，四台 VSG 内部的归一化 COI 权重在共同乘二时也不变；
- 修正后的直接 `M/D` 确定性方向在隔离诊断中仍有明显改善，方向可继续研究，但旧数值、选模结果与正式 guard 结论不可迁移；
- 两组修正后能量端口诊断均未达到 0.95 门槛，旧“正向构造性伴随结论”处于高风险，当前最符合证据的论文规划是**中等幅度重写**；
- 所有 SAC、源因子效应和交互数值都需要新的训练与评估，不能依靠“同一错误植物会在比值中抵消”。
