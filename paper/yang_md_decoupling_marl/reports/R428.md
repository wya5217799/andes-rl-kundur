## Observations

- **O-001 (CLM-1305) — Bank complete but CANARY-INVALID.** Nine manifests
  record 43,200 steps with valid convergence diagnostics (0 TDS failures);
  classification `CANARY-INVALID` because `all_rows_valid` is false
  (`formal_analysis.json#/classification/checks`).
- **O-002 (CLM-1305) — Scalar anchor bit-identical.** All three scalar
  checkpoints byte-identical to R419 (`scalar_anchor_vs_r419` all true) —
  the harness/driver is drift-free, so the failure is the SAC interface's,
  not the harness's (`formal_analysis.json#/scalar_anchor_vs_r419`).
- **O-003 (CLM-1305) — The exact interface collapses the policy.** In all
  six SAC runs alpha saturates at its declared ceiling 5.0 and the mean log
  probability reaches +10.36 to +10.90 (a near-delta policy), while the
  critic loss stays at ~1e8 scale (critic quartile ratio 0.25-0.78, a
  falling but enormous value) — the paper-strict reward (phi=[100,1,1], no
  abs term) diverges the value scale and collapses the entropy
  (`formal_analysis.json#/sac_diagnostics_readout`).
- **O-004 (CLM-1305) — The unslewed actions violate the actuator slew
  guard.** Every SAC eval block fails `action_slew_violation` (and hence
  `valid`), while the scalar arm passes all four row-validity checks — the
  paper interface has no slew projector, so the executed actions break the
  harness's actuator-rate constraint (`formal_analysis.json#/classification`
  + `summarise_profile` over the sealed eval records).
- **O-005 (CLM-1305) — Endpoints far worse than the deterministic
  reference.** SAC message-arm medians 0.00179 / 0.01084 (off-diagonal /
  disturbance) at 5.22 / 4.90 times the deterministic reference; the
  no-message arm 5.66 / 4.68 times.  The message increment is mixed
  (off-diagonal +7.7%, disturbance -4.6%), ≈0
  (`formal_analysis.json#/b1_table`).
- **O-006 (CLM-1305) — No slew saturation (no actuation).** The collapsed
  policy's executed actions are tiny, so slew saturation is ~0 and
  execution mismatch is 0 (no slew projector) in all six SAC runs
  (`formal_analysis.json#/b1_table/slew_diagnostics`).

## Conclusions

- **Finding, trust V.** The exact Yang-2022 TPWRS SAC interface, reproduced
  on the matched harness bundle, does not train a valid controller: the
  paper-strict reward (phi=[100,1,1], no absolute-frequency term) diverges
  the value scale (critic loss ~1e8), saturates the entropy coefficient at
  its ceiling, and collapses the policy to a near-deterministic tiny-action
  map whose unslewed actions violate the actuator slew guard in every block
  (CANARY-INVALID).  This instantiates the pre-registered R18 divergence
  risk as a measured, bounded negative result, not as a harness defect (the
  scalar arm stays byte-identical to R419).
- **Finding, trust V.** The reproduction turns the manuscript's
  "engineering baseline" caveat into a direct, same-harness comparison: on
  this physics, the paper's own SAC interface performs worse than the
  matched CD family (endpoints ~5x the deterministic reference versus ~2.5x
  for the repaired CD bundle) and never reaches a valid bank.
- **Evidence boundary.** One fixed-connectivity ANDES formulation, three
  seeds, the matched 43,200-step budget, the declared reconciliations
  (buffer no-clear, one gradient step per env step, tau 5e-3, alpha bounds,
  V-loss from [48], global grid-operator average); bounded to the tested
  bundle.

## Limits

  matched — no claim is made about the paper's own simulation.
- No tuning was attempted (pre-registered): a divergence/collapse is
  reported as measured, not repaired.
