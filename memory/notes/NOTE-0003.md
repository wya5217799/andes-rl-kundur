## Summary
The memory system (R39) optimized verdicts for the next agent — dense jargon, internal cross-references, hypothesis adjudication tables — not for the PI who wants research-story participation. R59 added a mandatory `## 给 PI 的话` section to every R59+ verdict, composed of five fixed sub-segments: 这周干了啥, 结果（一句话）, 意外, 我默认下一步做, 你想插一脚就说. The section is capped at ≤30 non-blank lines (soft warn). Critically, the agent must paste the full briefing body verbatim into the active chat as its closing turn — pointing to the file is non-compliant. `render.py` lifts the newest briefing to a top section of STATE.md and accumulates one-line headlines from all prior R59+ rounds.

## Key facts (claim candidates)
- Agent chat-delivery contract: paste `## 给 PI 的话` body verbatim in chat on round close; "see verdict.md" is non-compliant. Enforced by CLAUDE.md text, not tooling.
- `validate.py` enforces presence of the section for R≥59 verdicts and soft-warns when body exceeds 30 non-blank lines.
- `memory/glossary.yml` maps project terms to ≤30-char definitions; `render.py` annotates first occurrence per briefing as `term(definition)`.
