## Summary

External GPT Pro theory answer to the A1/A2 consultation brief (design aid;
no authority over sealed runs).  A1 verdict: placing the frozen total-action
effort term in the common channel is theory-neutral — R420 vs R422 differ by
the effective effort coefficient (1 vs lambda), the critic-head attribution,
and (when the dual reads the modified cost, which the R422 runner does) the
common episodic budget.  A2 verdict: the objective-to-gate gap is
structurally expected — the dual constrains an expected episodic quadratic
surrogate while the canary demands trajectory-level, reference-relative,
every-block guards; the action-stress guards need their own guard-aligned
RMS/TV constraints and multipliers; the actor's discounted Q_c and the dual's
undiscounted residual are not the same Lagrangian.  Key algebraic facts: c_c
contains differential frequency/RoCoF energy; effort is total action energy
(Parseval decomposition); R422's budget implies mean-effort <= 0.1 per
episode.

## Key facts (claim candidates)

- c_c exact modal decomposition (answer eq. A.2): common^2 + ||z||^2/4 over
  frequency and RoCoF — c_c is a common-protection surrogate, not a pure
  common-mode cost (verifiable against physical_costs in cd_matd3.py).
- R420/R422 scalarization difference = (lambda - 1) * J_e; identical at
  lambda = 1 (answer eq. A.6).
- R422 dual reads the modified c_c (effort consumes the budget 3.0):
  verified in the R422 runner training loop (episode_common accumulates the
  effort-augmented common_cost before lagrange_step).
- Actor critic is discounted (gamma 0.99) while the dual residual is an
  undiscounted 30-step sum: no single-Lagrangian saddle interpretation.
- Shared lambda is KKT-correct for one joint scalar constraint; the missing
  structure is per-guard multipliers (RMS/TV) aligned to guard units.
- Sample-budget necessary condition: mean effort <= 0.1 per episode implies
  normalized scalar action RMS <= ~0.2236 (loosest case c_c^0 = 0).
