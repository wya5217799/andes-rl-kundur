## Summary
The repository's flat root layout (through R36) mixed active code, frozen artifacts, infrastructure, and legacy snapshots as sibling directories with no package boundary. R37 adopted Option C — the standard `src/andes_rl_kundur/` layout — making the package `pip install -e .` installable and namespaced to avoid collisions in shared venvs. Entry-point scripts remain at top-level `scripts/`; frozen products (`paper/`, `dissertation/`) moved under `artifacts/`. Internal imports shifted from bare `from agents.sac import ...` to `from andes_rl_kundur.agents.sac import ...` across all active modules.

## Key facts (claim candidates)
- Package name `andes_rl_kundur` (matches repo name); layout conforms to PEP 517 `[tool.setuptools.packages.find] where = ["src"]`.
- R37 verdict (claim series) records paper-cited file relocations and confirms JSON-equivalence of `paper_grade_axes.py` outputs before and after the rename (AD-11 acceptance test).
- Reverting to a flat root (Option A) is explicitly marked "effectively irreversible" in the ADR; sub-decisions within the package (adding submodules, moving files) remain low-cost reversible.
