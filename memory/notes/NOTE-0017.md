## Summary
Engineering notes for modifying the ANDES Kundur 4-VSG environment; mandatory reading before touching any `env/andes/*`, `scripts/train.py`, or evaluation paths. Documents the collapse of the prior "paper-level" cum_rf claim: all 21 checkpoints score 0.033-0.036 / 1.0 on the 6-axis evaluation introduced 2026-05-07, with 5/6 axes failing (only smoothness occasionally reaches 0.7-0.9). Covers the progression of env versions V1→V2 (paper-faithful), reward weight decisions (PHI_F=10000, PHI_D=0.05), dt bug fix, best-vs-final checkpoint verdict, and the 6-axis residual root-cause (D=0 + no governor on GENROU, not H). Establishes a probe-first workflow contract and code-modification contract (no-overwrite of V1/V2 baselines, new-subclass rule) for all future env work.

## Key facts (claim candidates)
- All 21 checkpoints score 0.033-0.036 / 1.0 on 6-axis eval (2026-05-07); cum_rf single-axis "paper-grade" claim superseded.
- V2 env: M₀=30 (H₀=15s), heterogeneous D₀=[20,16,4,8], NEW_LINE_X=0.20; no-ctrl LS1 cum_rf=-1.66 matches paper -1.61, but 6-axis still fails.
- dt bug fix (2026-05-05): `current_t = float(self.ss.dae.t)` prevented 3× time-scale error; post-fix dt=0.2s/10s matches paper §IV-A.
- Best-vs-final verdict: use `best.pt` not `final.pt`; final-epoch policies show critic loss rise + reward oscillation in 500 ep runs.
- 6-axis max_df residual is structural (all V1/V2 sweeps yield ≥0.5 Hz vs paper 0.12 Hz); root cause: D=0 + no governor on GENROU G1-G4, not H (H=6.5 verified consistent with Kundur [49]).
- PHI_D=0.05 "balanced" verdict: 3-seed check showed s42=5.4%, s43=29%, s44=72% LS2 cum_rf — unstable, not a genuine breakthrough.
- Probe-first workflow: use `probes/andes_common/` for ~10 min forensic probes before code changes (R10-R17 template library).
- Code contract: any baseline change (M₀/D₀/action range) → new subclass; never overwrite V1/V2.
