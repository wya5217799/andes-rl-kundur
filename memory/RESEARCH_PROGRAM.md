## Phase gates

### P0 — Per-VSG object and qualitative reproduction

- Bind each ANDES VSG unit to exactly one runtime agent and one independent
  action vector; prohibit central scalar or edge-agent substitution.
- Verify action-to-device identity, local/neighbour observations, joint plant
  response, nonzero actuator authority, and a measurable mismatch-induced
  differential oscillation before training.
- Use Yang et al. only as an algorithm/object/reward reference.  Do not chase
  undisclosed Simulink values or reuse historical checkpoints as evidence.

Exit only when the object gate passes prospectively.  Failure blocks training
and requires a plant/interface repair or abandonment of the fixed title.

### P1 — Deterministic decoupling and coordination

- Define decoupling as reduction of inter-VSG dynamic coupling and oscillatory
  differential motion caused by heterogeneous inertia, droop, and disturbance
  distribution.
- Establish one strong deterministic coordinator under the same observations,
  action bounds, update rate, storage headroom, and communication budget as the
  later learner.
- Freeze physical endpoints for differential-mode energy/dispersion, damping,
  frequency response, control stress, and constraint failures.

Exit only with a valid non-learning baseline and measurable residual headroom.

### P2 — Bounded residual per-VSG MARL

- Keep the validated deterministic controller as the prior.
- Train one actor per VSG; centralized training is allowed, but runtime actions
  and permitted messages remain per-VSG and independently executable.
- Compare deterministic-only, non-learning residual, independent RL,
  no-message MARL, message-enabled MARL, and safety-projected MARL with matched
  permissions and budget.

Exit only if message-enabled residual MARL improves preregistered physical
coupling/oscillation endpoints over the strongest matched non-learning method
without increased failures or control stress.  Otherwise close the learning
increment negative.

### P3 — Held-out conditions and safety

- Seal unseen operating conditions, parameter mismatch, disturbances, and
  communication failures before selecting a checkpoint.
- Report paired uncertainty, failed runs, hard constraints, fallback-to-zero,
  and action/energy use.
- Topology and VSG-count generalisation are journal-strength upgrades, not
  prerequisites for the first title-supported conference package.

### P4 — Real-time evidence and manuscript

- Add CHIL/PHIL or another high-fidelity platform only after the core title
  gates pass and the venue requires the stronger evidence tier.
- Draft only from claims and feeds registered to the active line.
