statement: |
  R261 confirmed and corrected a recurrent Bellman-target alignment defect in
  the TD3-LSTM family. At the first post-burn-in loss transition, the old
  update path warmed target state through `obs[t-1]` and then queried
  `next_obs[t]`, skipping the realised current `(obs[t], action[t])`.
  Target-critic hidden state was additionally replaced by the hidden state
  returned from the hypothetical `Q(next_obs, target_action)` branch, so later
  targets followed target-action history instead of realised replay history.

  A deterministic tagged-sequence regression reproduced the old target-actor
  input sequence `[10, 30]` where the correct sequence is `[10, 20, 30]`.
  The fix (a) aligns the target actor through current `obs[t]`, (b) advances
  target critics on the realised replay transition, and (c) evaluates the
  next-state target on a branch without mutating realised-history state.

  The regression covers 9 concrete agent classes: scalar TD3-LSTM, HReg,
  WarmH0, AFE, QR, QR-HReg, QR-AFE, WarmH0+QR, and WarmH0+QR+AFE. Historical
  checkpoints remain valid evidence for the legacy implementation, but they
  were not trained with the corrected recurrent TD target. R261 makes no
  performance-improvement claim and does not silently relabel old checkpoints
  as corrected TD3-LSTM.
