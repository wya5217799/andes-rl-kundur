  R91-W1 (D3 obs-sufficiency, offline 4-regressor MLP fits on cached SOTA
  rollout, 400 records = 4 agents × LS1+LS2 × 50 steps, ANDES wall 19s +
  regressor training 9s) finds the R57-R82 91-round plateau bottleneck is
  **value-horizon mismatch under paper γ=0.99**, not an obs-for-policy
  bottleneck and not an LSTM-h-memory mechanism:

  | Regressor | Median test R² across 4 agents |
  |---|---|
  | R2: obs → SOTA action (memoryless BC) | **+0.979** |
  | R3: (obs, h_actor) → SOTA action      | **+0.996** |
  | ΔR3−R2 (h_actor essentiality)         | **+0.018** |
  | R4: obs → next_obs (forward model)    | **+0.859** |
  | R1: obs → instant reward (γ=0)        | **+0.930** |
  | R1: obs → return γ=0.9                |  +0.048   |
  | **R1: obs → return γ=0.99 (paper γ)** | **−0.410** ❌ |
  | R1: obs → return γ=1.0 (undiscounted) |  +0.706   |

  **Three structural findings**:

  1. **The SOTA policy is essentially memoryless.** R² for obs alone →
     action = 0.979; adding the full 128-dim LSTM h_actor gain is only
     +0.018 (1.8% R²). The R56 pivot to recurrent actor (escape from the
     R49-R55 hexagon) yielded a policy whose *output* function is captured
     by a 2-layer MLP over the 7-dim obs — h_actor is doing very little
     useful work for action selection at test time. The LSTM may still
     matter for *training stability* (escape mechanism documented R56),
     but its representational contribution to the final policy is marginal.

  2. **Dynamics are near-Markovian in paper-faithful 7-dim obs.** R²
     for obs → next_obs = 0.859. The Markov assumption that V4 obs
     captures all state needed for one-step prediction holds reasonably.
     POMDP-style memory is not strictly required to predict where the
     state goes next.

  3. **Value at paper γ=0.99 is the failure mode.** obs → instant reward
     gives R²=0.93. obs → undiscounted total return gives R²=0.71. But
     obs → discounted return at paper γ=0.99 gives **R²=−0.41** —
     **worse than predicting the mean**. The discount factor in the
     [0.9, 0.99] range puts the SOTA value function in a regime where
     short-term and long-term reward mix in a way that current obs
     cannot disentangle. γ=0 (only-current) and γ=1.0 (sum-over-horizon)
     both work; γ=0.99 (paper choice) is the worst possible discount.

  **Mechanism reframing of the R57-R82 plateau** (supersedes the
  obs-aug / critic-architecture / actor-memory framings):

  - **NOT** an obs-for-action ceiling (CLM-0160 + this claim): obs
    suffices for the policy; R83 obs aug failure (W2 marginal 0.365 /
    W3 RED 0.328) is not because we lacked obs, it's because the bottleneck
    is downstream of the policy.
  - **NOT** an LSTM-h memory ceiling: actor h is mostly redundant.
    R56's recurrence pivot fixed the training-time collapse but didn't
    contribute representational power to the final policy.
  - **NOT** a critic-representation problem ([[CLM-0160]] on-manifold):
    critic IS concave-around-a_sota when h_critic is on-rollout.
  - **IS** a value-horizon mismatch at paper γ=0.99: under the paper
    discount, the value function cannot be expressed as a smooth function
    of current obs. The critic must rely on h_critic to bridge this gap
    (consistent with [[CLM-0160]] which showed h_critic was essential
    for critic confidence). But the actor doesn't use h to optimise
    against this value — actor is computing a near-myopic policy.

  **R85+ priorities (supersedes [[CLM-0160]] §R85+ ordering)**:

  - ✅ **γ ablation** PRIORITY 1 — train R72_w4 hyper at γ ∈ {0.9, 0.95,
    0.99 (baseline), 0.995, 1.0}. Expected: γ=1.0 or γ=0.95 may break
    the plateau by aligning value horizon with episode length / dynamics
    time-scale. **Blocked on [[Q-0015]] (`--gamma` flag silently ignored
    for td3_lstm)** — must fix that before this can be tested.
  - ✅ **Reward shape ablation** PRIORITY 2 — R72_w4 hyper on
    `V4Config.paper_strict_pure` (PHI_ABS=0, paper Eq.14 strict).
    PHI_ABS=50 dominates per-step reward; removing it may make value
    smoother in obs.
  - ⚠️ **Longer episode horizon** — increase STEPS_PER_EPISODE from 50
    to 100/150 to give γ=0.99 more sum-room. Cheap to test.
  - ❌ **Obs aug (R83 path)** — DOWNGRADED. obs is already 97% sufficient
    for policy; more obs ≠ better SOTA when bottleneck is value-mixing.
  - ❌ **Distributional critic / IQN (CLM-0154/CLM-0162 R86/R87 path)**
    — STILL DOWNGRADED. The critic's value estimation is correct on
    h_critic; adding a distributional head doesn't change the
    underlying horizon-mismatch.
  - ❌ **CTDE / attention msg-passing (multi-agent structure)** —
    DOWNGRADED. Each agent's individual obs-for-action is already
    near-perfect; communication won't help when the bottleneck is
    value not policy.

  **Caveat**: N=400 records, 80/20 split, 80 train + 20 test per agent
  is small. R² estimates have ~5-10% noise band. Negative R² for γ=0.99
  is well outside noise, but the magnitudes for γ=0.9 / γ=1.0 may shift
  with larger N. Follow-up R91-W2 could expand to multi-seed multi-IC
  rollouts for tighter bounds.

  **N=1 ckpt caveat**: R72_w4 SOTA only. Cross-ckpt replication on R63
  (CLM-0088 batch 512 SOTA) / R75 (W2 s59 hawe SOTA) would be the
  symmetric on-manifold counterpart to R86 cross-ckpt synthetic.
