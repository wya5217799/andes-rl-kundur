  **R112-W1 (env-side test of [[CLM-0188]] warm-h_0 Q-side architectural
  slack): decisively NEGATIVE on 6-axis, mildly POSITIVE on paper cum_rf**.
  R104's grad-ascent on (h_0, c_0) lifts Q at step 0 universally, but
  the resulting saturated step-0 action causes catastrophic 6-axis
  collapse on real ANDES trajectory.

  ## Methodology

  `scripts/r112_warmh0_env_eval.py`. For each scenario (LS1, LS2):

  1. Real env reset, capture obs_0 per agent (the step-0 obs IS identical
     across LS1 / LS2 — delta_u applied AFTER t=0.5s warmup; grad-ascent
     gives same h* for both scenarios as a consequence).
  2. Grad-ascent (h_0, c_0) starting from zeros, 500 Adam steps lr=0.05,
     maximise min(Q1, Q2)(obs_0, actor(obs_0, h_0, c_0), h_critic=0).
     Same recipe as R99 / R104.
  3. Use the warmed (h_0, c_0) per agent as LSTM init at episode start
     instead of zeros. All other rollout steps use the normal stateful
     recurrence (h advanced by env).
  4. Run 150-step deterministic eval, score canonical 6-axis geo +
     paper §IV-C cum_rf via `evaluation/summary.score_trace_files`.

  ## Phase 1 grad-ascent (matches CLM-0188 Q-side prediction)

  | agent | ‖a_zero‖ | ‖a_star‖ | Q_zero | Q_star | ΔQ_abs | ‖h*‖ |
  |---|---|---|---|---|---|---|
  | 0 | 0.170 | **1.408** | -0.141 | -0.091 | +0.049 | 12.7 |
  | 1 | 0.127 | **1.403** | -0.029 | +0.028 | +0.057 | 15.4 |
  | 2 | 0.288 | **1.410** | -0.164 | -0.114 | +0.050 | 11.5 |
  | 3 | 0.089 | **1.407** | -0.069 | -0.017 | +0.052 | 12.6 |

  Each agent's step-0 action norm goes from ~10-20% of max
  (max ‖a‖ = √2 ≈ 1.414) to ≈ 99.6% (saturated). ΔQ_abs > 0 universally.
  This replicates [[CLM-0188]] / [[CLM-0183]] (R104 / R99) finding
  exactly — Q-side lift is real.

  ## Phase 2 env-side rollout (refutes Q-side prediction for 6-axis)

  | metric | zero-h baseline | warm-h_0 | Δ |
  |---|---|---|---|
  | LS1 11-axis | 0.354 | **0.000** | -0.354 |
  | LS2 11-axis | 0.432 | 0.033 | -0.399 |
  | geo | **0.391** | **0.0165** | **-0.374** |
  | cum_rf | -0.068 | **-0.031** | **+0.037** (improvement!) |

  **geo catastrophically collapses (-95.8%)** despite Q-side lift.
  **cum_rf paradoxically improves +54%**.

  ## Mechanism interpretation

  The step-0 ‖a‖ ≈ 1.41 (saturated) action represents an extreme jolt
  to the power system right when the disturbance first hits. The
  critic believes this action would have higher Q (paper §IV-C cum_rf
  is what Q approximates), so:

  - **cum_rf improves**: the saturated step-0 action DOES reduce
    cumulative frequency deviation slightly — Q estimation was correct.
  - **geo crashes**: the 11-axis geometric mean penalises non-smooth
    action trajectories (ΔM/ΔD smoothness axes, action_box utilisation
    axis, P-balance axis). A 1.41 → policy-natural ‖a‖ transition at
    step 1 introduces severe non-smoothness. The 11-axis "punishes"
    this oscillation, even though the **physics outcome** (frequency
    suppression via cum_rf) is slightly better.

  This is **the cleanest empirical demonstration so far that the
  project's 6-axis geo metric and the paper's §IV-C cum_rf metric
  measure DIFFERENT things**. R104's Q-side architectural slack is
  cum_rf-positive (paper metric), geo-catastrophic (project metric).

  ## Implications for paper Section IV-D + agent optimisation

  1. **[[CLM-0188]] Q-side finding stands as a TRUE off-policy
     architectural slack**, but it is NOT a plateau-mechanism lever
     when measured by 6-axis. Add to [[CLM-0200]] synthesis: warm-h_0
     architectural slack is cum_rf-positive but geo-negative.
  2. R104's `R96 = Q-0022 warm-h_0 implementation` proposal (mentioned
     in CLM-0188 PI brief) needs revision: a learned h_init MLP would
     reproduce this catastrophic step-0 action OR be regularised away
     from grad-ascent argmax. The "feasibility" CLM-0188 reported is
     **Q-side feasibility only**.
  3. **The 6-axis geo metric is non-monotone in Q** at the step-0 boundary.
     This is a paper-Section-IV.A reward-vs-metric audit point.
