statement: |
  R383 creates `converter-vsg-pq-decoupling` as a separate prospective
  manuscript line because replacing the stopped `PV+GENCLS` active-power-port
  formulation with converter-level VSG devices changes the physical object,
  actuator authority, endpoints, initialization risk, and claim boundary. The
  existing `paralleled-vsg-marl` line remains experiment-side stopped and
  available only for bounded manuscript closure; its results, checkpoints,
  claims, thresholds, and wording do not transfer.

  The new line retains ANDES 2.0.0 and the Kundur two-area network connectivity
  and begins with four `REGCV1` devices, one independently auditable
  `Pref/Qref` interface per unit, and no controller or training. Its required
  order is object/initialization/signed authority, deterministic P/Q
  decoupling, non-learning headroom and information value, conditional
  residual MARL, then robustness and higher-fidelity evidence. A valid failure
  at any prerequisite gate stops that formulation without model substitution
  or an algorithm sweep.

  This is a trust-S governance decision, not evidence that four-device
  initialization, active/reactive authority, P/Q decoupling, learning
  necessity, stability, robustness, topology generalization, EMT, hardware, or
  deployment validity has been established.
