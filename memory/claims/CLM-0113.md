  R69 — paper_grade_axes upgraded **v2.x (8-axis) → v3.0 (11-axis)**.
  Adds 3 axes gating paper-figure-equivalent qualitative checks that v2
  was systematically blind to (per CLM-0110 motivation).

  ### New axes (DDIC only, no-control unchanged)

  **Axis 9 — `agent_min_activity`** (gate agent collapse)
  - `min over agents of max_t(|dH_i| + |dD_i|)`, normalized by threshold=50
  - score 1.0 = all 4 agents move ≥ 50 units, 0.0 = ≥1 agent dead

  **Axis 10 — `late_oscillation_inv`** (gate persistent oscillation)
  - `1 - clip(std(df_avg(t > 3s)) / 0.01, 0, 1)`
  - score 1.0 = late-time flat, 0.0 = std ≥ 0.01 Hz

  **Axis 11 — `agent_P_balance`** (gate ΔP monopolization)
  - `1 - (max - min) / (mean + ε) of |P_final|` per agent
  - score 1.0 = 4 agent ΔP near 1:1:1:1, 0.0 = 1-agent absorbs all

  ### Combination

  `overall = geo_mean(11 axes)` with soft-clamp 0.01 per axis.
