  ### Mechanism (hypothesis)

  paper-strict modes use **pure cum_rf reward** (no PHI smoothness term):
  - paper_strict_pure: reward = -|Δf| only
  - paper_strict_pure_radsec: reward = -|Δω_radsec| only

  paper_faithful adds:
  - PHI_ABS = 50 (smoothness penalty on action mean)
  - PHI_H = PHI_D = 0.0056 (per-step ΔH/ΔD smoothness)

  LSTM's BPTT chain through 25-step sequences seems to require these
  smoothness signals to learn stable hidden-state representations.
  Without PHI: LSTM trajectory exploration diverges, hidden state
  enters degenerate region, training collapses to single-agent or
  no-action policy.

  TD3/SAC (memoryless) don't need PHI for stability — they explore
  per-step independently. paper-strict modes work for TD3/SAC (CLM-0105
  TD3 paper-metric SOTA, CLM-0109 SAC paper-faithful SOTA).

  ### Implication

  - **LSTM is paper_faithful-mode only** (R72 W4 s54 canonical best uses default
    config which IS paper_faithful)
  - **Paper-strict modes are TD3/SAC territory** (memoryless algos)
  - **Multi-controller paper strategy (CLM-0118)** is structurally necessary,
    not just convenience

  ### Future work (deferred R73+)

  - Could test LSTM with reduced PHI (PHI_ABS=10 or 5) to find boundary
  - Could test LSTM + paper_strict + auxiliary smoothness loss
  - Not paper-blocking; LSTM in paper_faithful already SOTA on 6-axis
