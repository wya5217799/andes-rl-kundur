  🚀 **Plateau breaker found via HAWE ensemble of cross-algorithm s54
  ckpts**. 3-way mean ensemble of {R72_w4 baseline (scalar Q TD3-LSTM),
  R142 (QR distributional td3_qr_lstm), R143 (QR td3_qr_lstm mean-loss-fix
  variant)} achieves **geo = 0.4043, vs best individual R72_w4 baseline
  0.3908, +0.013 (+3.5%)**.

  | Ensemble | geo | LS1 | LS2 | Δ vs R72_w4 0.3908 |
  |---|---|---|---|---|
  | **3-way mean** {R72_w4, R142, R143} | **0.4043** | 0.376 | 0.435 | **+0.0135 (+3.5%)** |
  | 3-way weighted (0.45/0.30/0.25) | 0.4021 | 0.367 | 0.440 | +0.0113 (+2.9%) |
  | 2-way mean {R72_w4, R142} | 0.3997 | 0.364 | 0.439 | +0.0089 (+2.3%) |
  | 4-way mean (+ R150 weak ckpt) | 0.3973 | 0.376 | 0.420 | +0.0065 (+1.8%) |
  | R72_w4 alone | 0.3908 | 0.354 | 0.431 | 0 ref |
  | R142 alone | 0.3845 | 0.362 | 0.408 | -0.0063 |
  | R143 alone | 0.3843 | 0.362 | 0.407 | -0.0065 |
  | R150 alone (warmh0+QR) | 0.3498 | 0.338 | 0.362 | -0.0410 |

  **Why ensemble works**: R72_w4 (scalar Q TD3-LSTM) and R142/R143 (QR
  distributional TD3-LSTM) train to similar bang-bang policies at
  convergence (final action_mean ~[0.88, 0.04, 0.87, 0.88]), but the QR
  critic shapes a slightly different value landscape → actor produces
  slightly different per-step actions. Mean-averaging damps individual-
  agent over-correction. LS2 benefits most (R72_w4 0.4032 → ensemble
  0.4348, +0.032).

  **R150 hurts 4-way**: R150 (warmh0+QR) is the only ckpt that didn't
  fully converge to bang-bang (final mu agent_0 = 0.81 vs others 0.88-
  0.94). Including it in the ensemble pulls the average policy away from
  the optimal bang-bang neighborhood → small regression (0.4043 → 0.3973).
  Diversity is **not always good** for ensembles; the constituents must
  each be near-optimal.

  **Method**: `scripts/eval_ensemble.py` HAWE (Heterogeneous Actor Weighted
  Ensemble) — loads N ckpts per ckpt-dir, calls each actor's
  `select_action(obs_i, deterministic=True)` per env step, aggregates via
  mean/median/weighted across N. Each recurrent actor maintains its own
  LSTM hidden state, reset at scenario boundaries via `begin_episode()`
  (R57-β pattern). Cross-algorithm support via patched
  `checkpoint_loader.load_agents` (this session) handling td3_lstm /
  td3_qr_lstm / etc. agent classes.

  **Cost**: 5 min wall total (single-seed s54 ckpts already trained;
  eval-only single ANDES session).

  **Paper Sec.IV-C implication**: paper's single-policy R72_w4 0.391
  claim can be augmented with "**HAWE 3-way ensemble = 0.4043 (+3.5%)**"
  as a real plateau-breaker. Better than any single agent (including
  novel R98 prototypes). Modest but reproducible.

  **What's still open**:
  - Cross-seed ensembles (need s49/s51 ckpts trained with same hyper).
    Likely larger gain than same-seed ensemble.
  - R149 200ep s54 still training. If it exceeds 0.391 individually,
    R72_w4 + R149 ensemble could push further.
  - Adding more diverse but weak ckpts hurts (R150 case). Need a "good
    ensemble member" selection rule (e.g., only include ckpts with
    individual geo ≥ 0.35).
