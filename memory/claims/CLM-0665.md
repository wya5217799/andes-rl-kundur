statement: |
  R290 closes Q-0047 partially with `ROOT-CAUSE-BOUNDED-NO-VALID-PATH`.
  A deterministic q0/Line_2 reproducer showed that R289's direct
  post-setup write to `Line.u.v` bypassed the ANDES model setter: TDS
  initialization failed, system exit_code was 1, and the maximum differential
  residual was 0.0283703. Replacing only that mutation with the public
  `Line.set` API made TDS.test_ok true, exit_code zero, and the maximum
  residual 3.19836e-08. Connectivity refresh added no change, and applying
  the same status immediately before setup produced the same valid
  initialization.

  Across all three valid-initialization paths, the Line_2/q0 case retained
  exactly two eigenvalues above the registered 1e-7 real-part tolerance with
  identical maximum real part 0.0458362. Therefore the positive pair is not
  caused by the direct-mutation initialization defect in this model, and none
  of the registered methods is eligible for a topology-value matrix. R290
  also introduced an explicit q0-first allocation-order list whose order
  survives canonical JSON key sorting.

  Scope: this is execution-validity and feasibility evidence. It fixes the
  future API/guard contract but does not estimate topology-information
  headroom, compare controllers, establish general stability, or authorize a
  new value matrix, time-domain run, learner, or GNN. A future question would
  need a prospectively selected q0-initializable and q0-stable topology bank.
