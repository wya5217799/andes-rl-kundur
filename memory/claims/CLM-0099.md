statement: |
  R65 W2 — **LSTM + R64 hyper combo DEGRADES 6-axis by -24 %** vs
  R57-α baseline. Hyper transfer does NOT generalize from memoryless
  algorithms (TD3, SAC) to recurrent LSTM.

  ### W2 — LSTM + R64 combo 3-seed

  Config (no Q-0007 to avoid Q-0010 bug):
  ```
  N_SUBSTEPS=3 MAX_GRAD_NORM=0.5 LR=3e-3 batch_size=512
  algo=td3_lstm normalize-actions hidden=64 episodes=75
  lstm-lr-warmup-eps=5
  ```

  Note: `LR=3e-3` is silently clamped to 1e-4 in train.py:305
  (CLM-0100), so effective LR=1e-4. The other axes (nsub, gc, bs) DID
  apply.

  | seed | best.pt | final.pt | R57-α baseline |
  |---|---|---|---|
  | s49 | 0.110 ⚠️ | 0.229 | 0.333 (-67 %) |
  | s51 | 0.437 | 0.426 | **0.526** (R57 SOTA, -17 %) |
  | s53 | 0.433 | 0.367 | 0.437 (≈) |
  | **3-seed mean** | **0.327** | 0.341 | **0.432** (**-24 %**) |

  ### Mechanism

  One or more of (N_SUBSTEPS=3, MAX_GRAD_NORM=0.5, batch_size=512)
  hurts LSTM training. Candidates:
  - **gc=0.5 too aggressive for BPTT**: LSTM gradients through time
    have higher magnitude (chain rule across 25-step sequences),
    aggressive clip caps them too early
  - **bs=512 too memory-heavy for LSTM seq replay**: forces fewer
    sequences per gradient step, slows convergence
  - **N_SUBSTEPS=3 dynamics shift**: LSTM trained for fewer ODE
    substeps may transfer worse to N_SUBSTEPS=5 eval

  Per-axis isolation deferred (Q-0013).

  ### Implication for production

  **6-axis Mode SOTA unchanged**: CLM-0067 R57-α s51 = 0.543 + R57-β
  HAWE-LSTM top2 = 0.501 (CLM-0066) remain best.

  Training command for new LSTM ckpts: stick with R57-α defaults
  (no R64 hyper combo for LSTM path).

  ```
  # R57-α command (no env vars, default lr=1e-4 clamp applies)
  python scripts/train.py --algo td3_lstm --normalize-actions \
    --episodes 75 --seed <S> --hidden-size 64 --lstm-lr-warmup-eps 5
  ```

  ### Asymmetry with TD3/SAC

  Same combo lifts TD3 +37.5pp (R64) and SAC +32.7pp (R65 W1) vs
  paper DDIC, but degrades LSTM by -24 %. **Hyper transferability is
  algo-class-dependent**, not universal.

  This is a paper-relevant finding: "Our hyper-optimized TD3/SAC
  produce SOTA paper-metric results; LSTM (R56-R57 SOTA on 6-axis)
  uses a different, R57-tuned hyper path".
