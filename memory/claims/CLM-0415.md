  ### Implication

  The 75ep training budget appears to be a structural sweet spot
  for the SOTA hyperparameter family on V4 ANDES Kundur 4-VSG, NOT
  merely an under-trained convenience. This holds across:
  - Algorithm variants (hreg via R191; scalar via R245)
  - Reward variants (full reward via R191; only-phi_abs via R245)
  - Seeds (s54 — both R191 and R245)

  This adds a **horizon dimension** to the multi-axis-fragility
  finding from CLM-0350/0360 (R190-R194). The "fragility manifold"
  for SOTA-class configurations now spans:
  1. Seed (s54 only safe; s49/s50 collapse)
  2. RNG path / env-reset offset (offset=0 safe; offset>0 degrades)
  3. **Horizon (75ep safe; 150ep/200ep regress universally)**
  4. Action bound (default safe; widebound regresses)
