  R98-W2 implements **TD3-QR-LSTM** (CLM-0157(a) distributional critic
  prototype): drop-in replacement for ``TD3LSTMAgent`` where the critic
  head emits N=51 quantiles per Q network (Dabney et al. 2018 QR-DQN
  canonical) and the critic loss is quantile-Huber instead of MSE. The
  actor backbone is unchanged. New files:

  - ``src/andes_rl_kundur/agents/networks_critic_variants.py`` —
    ``RecurrentQRQNetwork`` + ``RecurrentQRDoubleQCritic`` (twin
    QR critics with independent LSTMCell hidden states) +
    ``quantile_huber_loss`` (asymmetric τ-weighted Huber per Dabney
    Eq. 3, κ=1.0).
  - ``src/andes_rl_kundur/agents/td3_qr_lstm.py`` —
    ``TD3QRLstmAgent(TD3LSTMAgent)`` overrides ``__init__`` (replaces
    critic with QR variant), ``update`` (quantile-Huber loss + min-Q
    target trick at scalar-mean comparator level, preserving the
    full quantile vector for the loss), and ``save`` (writes
    ``algo: "td3_qr_lstm"`` + ``n_quantiles`` hparam).

  **Test verification** (``tests/test_critic_variants.py``, 22/22 pass
  on Windows native pytest with ``andes`` stub injected):
  - quantile-Huber loss unit tests: zero at constant-target +
    constant-pred, positive elsewhere, batch-mean broadcasts linearly,
    asymmetric weighting symmetric under sign-flipped δ at central τ
  - QR Q network forward returns ``(B, n_quantiles)`` + correct LSTM
    hidden shapes; twin critic returns ``(q1, q2, h_new)`` with
    independent hiddens
  - ``TD3QRLstmAgent`` satisfies ``BaseAgent`` Protocol,
    ``is_recurrent=True``, ``algo_name="td3_qr_lstm"``,
    default ``n_quantiles=51``
  - ``update()`` returns finite ``critic_loss`` + ``actor_loss``
    (~1e-2 magnitude) after 3 dummy episodes
  - backprop populates critic quantile-head weight gradient with
    shape ``(n_quantiles, hidden)`` and at least one nonzero row
  - ``save`` / ``load`` roundtrip preserves deterministic actor
    output bit-exactly (atol=1e-6) across a 20-step trajectory
  - checkpoint carries ``algo="td3_qr_lstm"`` + ``n_quantiles`` field

  **Existing td3_lstm regression**: ``tests/test_td3_lstm_agent.py``
  15/15 pass unchanged (verified via Windows-stub injection). R98
  adds new files only; ``agents/td3_lstm.py``, ``agents/networks.py``,
  ``train.py`` are NOT modified.

  **Mechanism intuition** (CLM-0150 / CLM-0157(a)): scalar TD critic +
  bilinear LSTM first-layer → critic learns ``Q(s, a) ≈ affine in a``
  (CLM-0150 d²Q/da² ≈ 0, CLM-0148 monotone-Q, CLM-0170 bang-bang actor
  argmax saturation). A quantile head forces the critic to fit the
  FULL return distribution at every (s, a) — including its variance
  — which in QR-DQN / IQN literature reliably produces richer action-
  conditional representations even with identical actor.

  **Not yet trained**: per CLM-0157 "execution gated on R83 (obs-space)
  result". R98 delivers the code path; ``train.py`` integration is a
  1-line dispatch-table addition deferred to R99+ when R83 verdict
  lands. ``--algo td3_qr_lstm`` will then work without further file
  changes to agents/, networks/, or replay buffer.
