statement: |
  The R424 guard-aligned action constraints were implemented with a reward
  sign: in the sealed learner the actor loss is -mean(Q + lambda*Q_c +
  mu_RMS*RMS + mu_TV*TV) — the constraint terms sit inside the negation, so
  gradient descent maximizes the executed-action energy and TV statistics
  and the dual ascent keeps raising the reward weight (the frozen plan's
  appended-terms form penalizes them; a param-space gradient probe measures
  the update direction opposite to the penalty, inner product -97.6). The
  round's CANARY-FAIL is therefore the implementation-layer manifestation
  of the R423 constraint-hierarchy diagnosis, not a test of the mechanism
  as designed: action-RMS and action-variation stay 36/36 failed blocks,
  all 240 retained multipliers sit at the 10.0 ceiling with RMS residuals
  38.3-90.8x, both CD actors pin ~90% of action components at the actuator
  bounds (saturation-budget guard 0 -> 24), the endpoints regress to
  2.3419 / 1.7751 versus the deterministic reference (R419: 0.6954 /
  0.7104), and the message increment collapses to 0.0000 with bit-identical
  arms — the slew clip masks the message contrast, so no verdict on
  communication value is made; the same policy yields the family's best
  common no-harm profile (common-frequency 36 -> 12, RoCoF 22 -> 14,
  worst-peak 35 -> 24) and drains the common multiplier to 0 in 6/6, while
  the critic divergence persists (Q4/Q1 5.98-9.61, threshold 3 not met).
