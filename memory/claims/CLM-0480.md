  ### Mechanism — reward hacking via collective drift (NEW)

  Training log (output file `brw3oazri.output`) reveals the actor's policy
  evolution:

  | Episode | Reward | Actions mu (per agent) | Action std |
  |---------|--------|------------------------|------------|
  | Ep 9    | -77.8  | [-0.01, -0.03, 0.01, -0.02] | 0.55-0.60 |
  | **Ep 29** (best ckpt) | **-0.5** | [0.01, 0.13, -0.03, -0.01] | 0.09-0.11 |
  | Ep 39   | -9.6   | [0.07, 0.24, -0.01, 0.03]   | 0.09-0.11 |
  | Ep 49   | -15.4  | [0.31, 0.67, -0.01, 0.15]   | 0.11-0.18 |
  | Ep 59   | -8.1   | [0.76, 0.86, -0.01, 0.52]   | 0.17-0.21 |
  | Ep 69   | -0.7   | [0.83, 0.87, 0.01, 0.40]    | 0.15-0.22 |

  **Key insight**: the "best ckpt" at ep 29 had Actions mu ≈ 0 (near-zero
  per-agent). That is a **near-no-control policy** that minimizes training
  r_f because zero-action = system reaches some natural equilibrium with
  small sync residual (`(delta_f_i - mean(delta_f))²`). But eval geo = 0.000
  on both scenarios because the system has huge un-damped transient
  deviation — phi_abs's `|delta_f|²` term (the absolute transient penalty)
  was the ONLY signal pulling actor toward actually damping frequency.

  Without phi_abs, the only training reward (r_f = `-phi_f × sync_residual`)
  is REWARD-HACKABLE:
  - "all agents output same action" → `sync_residual = 0` → r_f = 0
  - "all agents output zero action" → minimal sync residual → near-zero r_f
  - "do nothing and let system reach natural equilibrium" → near-zero r_f
  Eval against actual Kundur transient dynamics exposes these as
  degenerate policies.

  ### Why R248 (phi_h=phi_d=1.0) collapses identically

  R248 used phi_h=phi_d=1.0 in normalize-actions mode (per R248/plan.md
  command). At those weights, r_h + r_d penalties dominate r_f scale-wise
  (mean(a)² ≈ 0.25 × 1.0 = 0.25 per agent vs r_f magnitude). Actor learns
  to minimize action-mean-squared penalty by outputting near-zero mean
  action. Result: degenerate "all output zero" policy. Same collapse
  signature as R258 because the EFFECTIVE training signal devolves to
  "minimize action drift" without compensating "damp transient" pressure.
