  **R171 — Ledger system Gap fixes (R166 follow-up)**. Implemented 4
  gaps discovered while answering "which experiments are unfinished":
  results↔ledger detection (Gap 1), Q-superseded-by-claim heuristic
  (Gap 2), `closed-partial` status enum addition (Gap 3), and
  `latest_research_round` filter (Gap 4). Surfaced and cleaned 5 more
  orphan rounds (R144/R147/R167 collapse; R169/R170 near-SOTA — the
  latter is paper-relevant per CLM-0325).

  ### Why this decision

  R166 fixed the open/close asymmetry but left a deeper layer
  untouched: parallel sessions running experiments without writing
  claims/verdicts. R166 sweep itself misclassified 3 such rounds
  (R144/R147/R167) as `aborted reserved-empty` because plan.md was
  absent — silently throwing away the eval results. R169/R170 nearly
  suffered the same fate, but the parallel session wrote CLM-0325
  documenting them just before this sweep ran. **Without Gap 1
  detection, R170's geo=0.4091 (single-policy near-SOTA) would have
  stayed in the orphan bucket forever**.

  ### What was added (Phase A)

  **Gap 1 — `R-results-orphan` rule** in `validate.py`. Scans
  `results/rNNN_*/final_eval_summary.json` files; warns when no
  current claim's `round` or `provenance` references the dir. Caught
  5 misclassifications on first run (R144, R147, R167, R169, R170).

  **Gap 2 — `warn_question_supersession` heuristic** in `validate.py`.
  Keyword-overlap match (≥3 ≥4-char tokens, stop-word filtered)
  between open Q title and recent CLM `statement` + `tags`. Soft
  warning only — surfaces candidates for human review, not auto-
  close. First run surfaced Q-0023 (mag-PI) as already-answered.

  **Gap 3 — `closed-partial` added to `QUESTION_STATUS_ENUM`** in
  `validate.py`. Q-0014's "algorithm-side breakthrough — yes via
  ensemble only" is the canonical motivating case; previously forced
  to `closed-positive` with caveat in `closed_note`.

  **Gap 4 — `latest_research_round` in `render.py`**. Adds `type`
  field to plan.md frontmatter ({research|meta|infra}); STATE.md
  `## Latest Round` and PI briefing prefer `type=research` rounds,
  falling back to latest-any. Prevents meta/infra rounds (R166, R171)
  from masquerading as the research front.

  7 new pytest cases (4 for Gap 1, 3 for Gap 2, plus the Gap 3
  enum test). 126 total pass.

  ### Cleanup done (Phase B, executed by `_r171_sweep.py`)

  - R168/R169/R170 reserved-empty stubs initially written, then 2 of
    them (R168, R169, R170) were RE-flipped to `state=completed` after
    Gap 1 + manual audit revealed eval results (parallel session work
    that hadn't yet been claimed at sweep time)
  - R144/R147/R167 misclassified-aborted → flipped to completed with
    retro verdicts (all geo ≈ 0.01 collapse)
  - R156/R157 → flipped to superseded by R158 (CLM-0300 documents)
  - R161 → flipped to superseded by R168 (CLM-0320 documents)
  - Q-0014 → re-flipped from closed-positive to closed-partial
  - Q-0023 → closed-positive by CLM-0256 (mag-PI matches droop)

  ### Trust rationale (S)

  Decision claim — schema choices (new rules + new enum value + new
  frontmatter field) and cleanup classifications. The R170 quantitative
  finding it surfaced is in CLM-0325 (trust V).

  ### What's still imperfect

  - The parallel session also wrote CLM-0325 (R170 finding) with
    round=R171 — meaning R171 is now both a meta round (per its plan)
    AND a research output (per CLM-0325 round field). Future
    convention: parallel sessions should reserve a new round number
    rather than write to one whose plan declares meta type. Not
    enforced by tooling yet; flagged as Gap 5 follow-up.
  - The keyword-overlap heuristic has noise: 4 of 6 open Q
    suggestions in first run were false positives (matched terms but
    not actual answer). Acceptable for soft-warn; not for auto-close.
  - Gap 5-9 from R166 follow-up audit deferred (see R166 verdict).
