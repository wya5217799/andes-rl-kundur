  ### Figure structure

  **Panel A (scatter)**: (cum_rf, geo) plane with 91 cached ckpts.
  Cluster regions shaded (red = degenerate geo<0.10; gray = mid;
  blue = LSTM SOTA geo>0.30). Points coloured by algo class. Three
  anchor ckpts annotated:
  - R75 W2 s59 (geo SOTA, CLM-0131)
  - R72_w4 (paper Fig 7 canonical, CLM-0123)
  - r67_w2a (cum_rf SOTA, CLM-0118)

  **Panel B (horizontal bar chart)**: per-algo % of ckpts in each
  cluster. TD3-LSTM (n=75): 37% degenerate / 16% mid / **47% LSTM SOTA**.
  SAC (n=3): 67% degenerate / 33% mid / **0% LSTM SOTA**. TD3-MLP (n=5):
  60% degenerate / 40% mid / **0% LSTM SOTA**.

  ### Why this figure matters for paper

  Single figure conveys **three quantitative paper claims** that until
  now lived only in dispersed text + scattered scatter plots:

  1. **Bimodal training outcome** (R139 / CLM-0264): policies cluster
     into two productive attractors + one failure basin.
  2. **Algo-exclusive LSTM SOTA** (R141 / CLM-0268): only recurrent
     actors reach geo > 0.30; 0/8 SAC+MLP combined.
  3. **Project's dual-SOTA strategy is structural, not stylistic**
     (CLM-0118 / CLM-0131 / CLM-0123): three named anchors visualised
     in their respective cluster locations on the same plane.
