  - **R72_w4 baseline**: all 4 agents at near-boundary (mean=0.9, sat=0.55).

  - **R129 QR alone**: 2 agents bang-bang (mean=0.9, sat 0.51), 2 agents

  **Mechanism — AFE input pathology**:
  AFE critic input is ``[obs, a, a², |a|, sign(a)]``. At ``a=0``:
  - ``a = 0``
  - ``a² = 0``
  - ``|a| = 0``
  - ``sign(a) = 0`` (torch.sign(0) == 0)

  All 4 action features collapse to zero. The critic sees the **cleanest
  input signal** (only obs), with no action-induced noise. Quantile-Huber
  (or scalar TD) loss converges fastest on this "no-action" regime
  because the target distribution Q(s, 0) has the lowest epistemic
  variance.

  The actor, training to maximize Q, finds that pushing ``a`` toward 0
  monotonically increases the critic's evaluation **because** moving
  away from 0 introduces multiple nonlinear features (a², |a|, sign-flip)
  that the critic hasn't fit as cleanly. Net effect: actor converges to
  ``a ≈ 0`` (do-nothing attractor) regardless of state.

  In TRAIN (50-step horizon), do-nothing scores well: natural damping
  handles the LS1/LS2 step disturbance within 50 steps, and the
  PHI_ABS=50 action penalty disappears at a=0. Train_reward = -5.9 looks
  "great" but is reward-gaming.

  In EVAL (150-step horizon, paper-grade), do-nothing fails: with
  PHI_ABS=50 multiplier removed and sustained perturbation profile,
  the actor must sustain damping action; do-nothing → TDS divergence
  on LS1/LS2 → geo collapses to floor 0.01.

  R129 (QR alone, no AFE) escapes the pathology partially: 2 agents
  develop bang-bang because the [obs, a] critic input does not have
  the zero-action attractor; the asymmetric 2-of-4 attractor split is
  itself unexplained but matches the LS1-vs-LS2 asymmetry in
  ``paper_grade_axes`` (LS2 = Bus 15 Area 2 disturbance, agents 0&1 sit
  in Area 2, hence they bang-bang on LS2).

  **Design implication for CLM-0157(b)**: AFE input feature engineering
  as implemented in R98 is **counter-productive at 75 ep paper-faithful**:
  the zero-action attractor is faster to fit and lower variance than
  the bang-bang attractor R72_w4 baseline finds. To salvage AFE, the
  feature design must avoid ``a=0`` being the unique multi-feature null:
  e.g. replace ``sign(a)`` with ``tanh(k·a)`` for ``k`` large (so 0+ε ≠ 0
  in feature space), or add a constant offset like ``a + 0.1``. Or drop
  AFE entirely and rely on output-side fixes (QR R129 partial survival
  hints AFE input is the disabling factor).

  **Predicted falsification**: if R98 td3_afe_lstm with seed=54 (R123,
  queued by other session, NOT yet launched) lands at geo 0.001-0.05
  with all-4-agents-near-zero action_mean → confirms attractor is

  **Predicted longer-horizon outcome**: if R98 td3_qr_afe_lstm at 500 ep
  reaches the bang-bang attractor (action_mean approaching 0.9 instead
  of 0) → 75 ep is too few for AFE-modified critic to learn quadratic
  curvature properly. Q-0008 (paper 500-ep convergence horizon) hint
  applies. Otherwise AFE design is *structurally* broken at this
  network architecture.
