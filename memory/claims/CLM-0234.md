statement: |
  R127-W2 ships **triple-stack agent code** (warmh0 actor + QR critic
  + AFE input) as a drop-in `--algo td3_warmh0_qr_afe_lstm` for
  ``scripts/train.py``. This combines three orthogonal plateau-breaker
  interventions documented in prior closed claims:

  1. **WarmH0 actor** (R96 / R107 / R109 / CLM-0188 / CLM-0193):
     replaces zero-init ``(h_0, c_0)`` with a learned MLP head over the
     first-step obs. CLM-0188 showed 9/9 cross-ckpt feasibility (median
     8.5%→95.6% step-0 action norm unlock, ΔQ_abs always positive).
  2. **QR distributional critic** (R98 / CLM-0157(a) / CLM-0189): 51-
     quantile head + quantile-Huber loss (Dabney 2018). Forces critic to
     fit full return distribution, not just mean.
  3. **AFE critic input** (R98 / CLM-0157(b) / CLM-0190): augments critic
     input from ``[obs, a]`` to ``[obs, a, a², |a|, sign(a)]``. Gives
     the bilinear LSTM-cell first layer a linear pathway to quadratic
     action features, addressing CLM-0150's d²Q/da² ≈ 0 affine-Q
     pathology.

  **New files**:
  - ``src/andes_rl_kundur/agents/td3_warmh0_qr_afe_lstm.py``
    (236 LoC). ``TD3WarmH0QRAfeLstmAgent`` inherits ``TD3QRAfeLstmAgent``
    (R125 stacked QR+AFE) and overrides ``__init__`` (actor → WarmH0),
    ``select_action`` / ``select_action_recurrent`` (thread obs_t to
    ``init_hidden(obs_for_warm=)`` at episode start), and ``update``
    (warm-h_0 init for actor + quantile-Huber loss for critic combined).
    Critic side stays zero-init per R107/R109 warmh0 convention.
