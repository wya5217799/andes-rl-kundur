statement: |
  R262 evaluated the pre-registered static blend
  `a=(1-alpha)*a_R201+alpha*a_droop(k=10)` at
  `alpha={0,.1,.25,.5,.75,.9,1}` on canonical LS1+LS2 with real ANDES.
  The endpoints exactly reproduced R201
  (`geo=0.415239`, `cum_rf=-0.069158`) and droop k=10
  (`geo=0.179184`, `cum_rf=-0.036712`).

  Every interior point traded lower `geo` for less-negative `cum_rf`; none
  beat both endpoints and none passed the pre-registered balanced gate
  (`geo>=0.35` and `cum_rf>=-0.055`). Alpha 0.10 improved `cum_rf` by 7.47%
  while reducing `geo` by 2.99%; alpha 0.25 retained `geo=0.372745` but
  reached only `cum_rf=-0.057163`.

  Therefore fixed convex action blending supplies a tunable Pareto control
  baseline but does not achieve the project's strict dual-metric objective.
  Scope is seed-42 LS1+LS2 on the frozen legacy-control-Hz metric basis, with
  a legacy-trained R201 recurrent component; it is not evidence about
  corrected-R261 recurrent training or held-out topology robustness.
