  ❌ **R244 (SAC, seed=54, episodes=75, default hyper, full reward) =
  geo 0.0100, LS1=0.0, LS2=0.0, cum_rf=-0.2023** — SAC at default

  paper-metric era).

  ### Interpretation

  This is **NOT** a paper-integrity finding. SAC was trained with
  the **full** V4 reward (phi_abs=50, phi_h=0.0056, phi_d=0.0056,
  phi_f=100), not paper-strict. The collapse therefore reflects an
  algorithm/hyperparameter issue specific to SAC at default hyper,
  not a reward-structure issue.

  Adding SAC to the autonomous-loop algorithm sweep does **not**
  contribute a new paper Sec.IV-D dimension as initially hoped
  ("entropy-regularized algo class"). The result re-confirms an
  older finding (CLM-0101) that SAC requires substantial hyper-
  tuning on this env which the autonomous loop's default
  configuration did not provide.

  ### What this doesn't test

  - Whether SAC + only-phi_abs vs SAC + paper-strict shows the
    same gauge-invariance pattern (R244 didn't test paper-strict
    on SAC).
  - Whether SAC with tuned hyper could match TD3+LSTM SOTA — would
    require a hyper sweep round dedicated to SAC.

  ### What this implies for next steps

  Adding SAC to the paper-integrity matrix would require:
  1. Tune SAC hyper to baseline parity with TD3 (~0.39+) at full
     reward — likely 5-10 rounds of hyper sweep, low ROI given
     plateau is already confirmed structural.
  2. THEN test SAC + paper-strict to extend gauge-invariance
     finding. Tier-2 priority at best.

  More valuable next-round candidates:
  - R245 (already launched): scalar + only-phi_abs at 150ep — tests
    horizon effect on the universal-inertness finding.
  - R246: scalar + only-phi_abs at s50 — tests if R242 (-15.7% at s51)
    is single-seed quirk or generalises.
  - R247: scalar + phi_h alone at s51 — decompose which paper term
    recovers the R242 LS2 deficit.
