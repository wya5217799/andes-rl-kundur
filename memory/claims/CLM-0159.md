  ### Q-0016 fix (R81 W2 final_eval crash → R83 fixed)

  Root cause: `scripts/train.py::_emit_final_eval` 重建 eval env 时没把
  `INCLUDE_OWN_ACTION_OBS` env var propagate 给 V4Config. eval env 默认
  obs_dim=7, LSTM actor 学到 obs_dim=9 → crash at `td3_lstm.py:242`
  select_action LSTMCell forward.

  Fix in `scripts/train.py::build_v4_config()`:
  ```python
  include_action_env = bool(int(os.environ.get("INCLUDE_OWN_ACTION_OBS", "0")))
  include_time_env  = bool(int(os.environ.get("INCLUDE_TIME_OBS", "0")))
  include_area_env  = bool(int(os.environ.get("INCLUDE_AREA_MEAN_FREQ_OBS", "0")))
  if include_action_env: overrides["include_own_action_obs"] = True
  if include_time_env:   overrides["include_time_obs"] = True
  if include_area_env:   overrides["include_area_mean_freq_obs"] = True
  ```

  V4Config 现在是 obs aug 单一 source of truth (ADR-0002 精神). final_eval
  env 通过 V4Config field 拿到完整配置, dim mismatch 不再发生.

  ### V4Config 互斥解除

  V4Config `__post_init__` 之前 raise NotImplementedError 不让 own_action +
  time 并存 (R52 slot-layout 设计未做). R83 删互斥 check, 改成绝对 slot
  索引在 base_env 实现.

  ### base_env obs slot refactor

  `base_env._build_obs` 改成绝对 slot 索引:
  ```
  obs[0:7]  = base (3 + 2 * MAX_NEIGHBORS)
  obs[7:9]  = own_action (if include_own_action_obs)
  obs[?]    = time (if include_time_obs)
  obs[?:?+2] = area_mean_d_omega (if include_area_mean_freq_obs)
  ```
  顺序固定, 任意子集开/关. OBS_DIM 累加: base 7 + own_action 2 + time 1 +
  area_mean 2 = 最大 12.

  ### V4Config 新 field

  `include_area_mean_freq_obs: bool = False` — 当 True, OBS_DIM += 2, 每
  agent obs 末加 (area1_mean_d_omega, area2_mean_d_omega). paper Fig.3
  area 分组: agent 0/1 (bus 12/16) → area 1, agent 2/3 (bus 14/15) → area 2.

  ### 资产保护

  V4 regression test `tests/test_v4_env_regression.py` 1e-9 仍 PASS (93s)
  post-refactor. R57+ SOTA ckpt eval 行为不变 (默认 include_*_obs = False).
