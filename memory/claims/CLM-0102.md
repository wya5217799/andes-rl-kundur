  R66 — Q-0010 fix landed and **empirically verified**.

  ### Bug root cause

  `paper_path.py:148-152` comment exposes ANDES constraint:
  > "Always release the ANDES TDS session; single-session limit
  > on Windows (NOTES_ANDES.md) makes a leaked env fatal for the
  > next run."

  Pre-R66 train.py eval probe (R61 placement) ran BEFORE `env.close()`.
  Created new ANDES env while training env still open → session conflict
  → silent LSTM state corruption (CLM-0099 mechanism).

  ### Fix

  Two changes in `scripts/train.py` ep loop:

  1. **Eval probe moved AFTER `env.close()`**:
     ```
     run_episode() → save ep snapshots → env.close()
     → eval probe (creates new env, doesn't conflict)
     ```
  2. **RNG state save+restore** around eval probe:
     ```python
     np_state = np.random.get_state()
     torch_state = torch.get_rng_state()
     try:
         eval_score = evaluate_agents_paper_metric(...)
     finally:
         np.random.set_state(np_state)
         torch.set_rng_state(torch_state)
     ```
     Prevents eval rollouts from shifting training stochastics
     (secondary defense, even though primary cause is ANDES session).

  ### Verification

  Ran LSTM s51 + Q-0007 (`--eval-every-n-eps 5`) with fix:

  | ckpt | s51 6-axis |
  |---|---|
  | R57-α today reproduction (no probe) | 0.4259 |
  | **R66 W2 LSTM + Q-0007 fixed best.pt** | **0.4259** ✓ matches |
  | R66 W2 best_eval.pt | 0.4130 |
  | R62 W1 unfixed Q-0007 | 0.115 (broken, -78 %) |

  **Contamination eliminated**. LSTM + Q-0007 best.pt now matches
  the no-probe reproduction baseline.

  ### Implication

  - LSTM training can now use `--eval-every-n-eps 5` safely
  - But best_eval (paper-metric peak) ≠ best (train-reward peak) for
    LSTM because 6-axis ≠ paper-metric. LSTM Q-0007 value is on
    paper-metric path, not 6-axis path.
  - LSTM 6-axis SOTA remains R57-α s51 = 0.526 (historical ckpt)
  - **Q-0010 closed-positive** — Q-0007 now safe for all algorithms

  ### Implication for paper-metric

  Untested: LSTM + Q-0007 on paper-metric (cum_rf). Should give
  >+14 % lift (SAC/TD3 pattern). Would also need:
  - 3-seed verify
  - Compare to current SOTA SAC (R65 W1, -0.194)
  - Decide if LSTM beats SAC under paper-faithful eval
