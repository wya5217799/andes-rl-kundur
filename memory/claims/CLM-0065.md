  **Implementation notes**:
  - R57 v1 of lr-warmup had a counter-placement bug: `_episode_count`
    incremented in `begin_episode()` consumed by env-warmup phase,
    expiring the warmup window before training started. Wave-1 v1
    produced bit-identical results to R56-α (the diagnostic that
    exposed the bug). Fixed by gating the counter increment behind
    `_this_episode_seen_update` inside `update()`. Regression test
    `test_lr_warmup_skips_episodes_without_updates` locks the seam.
  - Code review (parallel code-reviewer + python-reviewer) before
    commit surfaced 2 HIGH + 6 MEDIUM issues; all R57-scope fixes
    applied (one-shot `_warmup_done` flag, multi-update-per-episode
    test coverage, type annotations, `LSTM_GATE_COUNT` constant,
    `isinstance` over `hasattr(__len__)`, `flush_episode` flag reset).
