  R61 — Q-0007 full implementation landed.

  ### Changes (one commit, 3 source files + 1 test file + 10 tests)

  **`src/andes_rl_kundur/evaluation/paper_strict_eval.py`** —
  added `evaluate_agents_paper_metric(agents, *, config=None,
  scenarios=None, seed=42, steps=50)`:
  - Default scenarios = `ANCHOR_PAIR` (paper LS1 + LS2)
  - Returns mean `cum_rf` (less negative = better)
  - Sentinel `-1e6` on all-TDS-fail
  - Cost: ~5 s/call

  **`src/andes_rl_kundur/utils/monitor.py`** — extended `TrainingMonitor`:
  - New ctor param `best_eval_callback: Callable[[int, float], None] | None`
  - New `_best_eval_score: float = -inf` + `_best_eval_episode: int = -1`
  - New method `update_eval_score(episode, eval_score) -> bool`
    (strict-improvement firing rule)
  - Persisted in `save_checkpoint` + restored in `load_checkpoint`

  **`scripts/train.py`** — added `--eval-every-n-eps N` CLI flag:
  - Default 0 (disabled)
  - When > 0, every N episodes after warmup (total_steps >= warmup
    gate, preventing CLM-0073 pre-training spike pathology), call
    `evaluate_agents_paper_metric()` and dispatch to `update_eval_score`
  - `on_best_eval` callback saves `agent_i_best_eval.pt` +
    `ctde_critic_best_eval.pt` parallel to existing best.pt
  - Backward compatible: all R56/R57/R58 training commands work
    unchanged (N=0 = no-op)

  **`tests/test_q0007_eval_tracked_best.py`** (new) — 10 TDD tests:
  - Monitor.update_eval_score: first-call, strict-improvement, equal,
    no-callback, persistence, independence-from-reward-callback (6)
  - paper_strict_eval.evaluate_agents_paper_metric: returns-float,
    TDS-sentinel, anchor-pair-default (3)
  - CLI: --eval-every-n-eps flag presence + default (1)

  ### Test results

  `pytest tests/ -q` → **160 passed, 0 failed** (150 baseline + 10
  new). Mid-implementation refactor broke 9 pre-existing tests by
  accidentally splicing `update_eval_score` into `log_and_check`;
  fixed by relocating after the existing return.

  ### Operational guidance

  **Recommended N** for new training:
  - 75-ep training: N=5 → 14 eval probes × ~5 s = ~70 s overhead
    (~8 % wall on 15-min training); acceptable
  - 500-ep training: N=10 → 49 probes × ~5 s = ~4 min on 72-min training
    (~5 % wall); acceptable
  - 2000-ep training (paper-aligned): N=20 → 99 probes × ~5 s = ~8 min
    on ~4-hr training (~3 % wall); negligible

  **When to enable**: any training that adds large reward-shaping
  terms (PHI_ABS, anti-smoothness, restoration). CLM-0073 + CLM-0075
  showed best.pt locks at pre-training spike in these cases —
  `best_eval.pt` is the only correct artifact.

  **When safe to skip**: 75-ep training with default
  paper_strict_pure_radsec or paper_faithful config (CLM-0079 showed
  4/5 R57 seeds had best.pt at natural training peak under that
  config). But Q-0007 is cheap insurance.

  ### Supersession

  This decision **does not supersede** any prior CLM. It implements
  Q-0007 (open since R57), advancing it from speculation to runnable
  code. Empirical Q-0007 payoff measurement is in CLM-0079.
