  🚨 **R255 probe (no env change, 10-min analysis per NOTES_ANDES.md
  probe-first protocol) REFUTES the local-vs-global r_f mismatch
  hypothesis**: for the Kundur 4-node ring topology, local r_f
  (training reward, sum over agents with 3-agent local mean) and
  global r_f (paper §IV-C cum_rf, 4-agent global mean) are linked
  by a **constant 2.66× scaling factor** across ALL controllers
  (RL, droop, no-control). Both metrics rank controllers
  identically; the RL cum_rf plateau is therefore NOT a metric-
  mismatch artifact.

  ### Probe data (LS1 trajectory, time-integrated per-step r_f)

  | Controller | local r_f | global r_f | local/global |
  |------------|-----------|-------------|--------------|
  | R201 hreg SOTA (geo-best) | -0.1116 | -0.0419 | **2.66×** |
  | R254 phi_f-only | -0.1514 | -0.0568 | **2.66×** |
  | R246 only-phi_abs | -0.1618 | -0.0607 | **2.66×** |
  | Droop k=10 (cum_rf-best) | -0.0660 | -0.0248 | **2.66×** |
  | Droop k=2 (geo-best classical) | -0.1033 | -0.0387 | 2.67× |
  | No-control | -0.3168 | -0.1188 | 2.67× |

  Provenance: `scripts/r255_probe_local_vs_global_rf.py`,
  `results/r255_probe_local_vs_global_rf.json`.

  ### Mechanism (topology arithmetic)

  Kundur ring `COMM_ADJ = {0:[1,3], 1:[0,2], 2:[1,3], 3:[2,0]}`.
  Each agent's local r_f penalty sums over its 3-agent neighborhood
  (self + 2 neighbors). Each agent k is contained in 3 such
  neighborhoods (its own + 2 of its neighbors that have it in their
  neighborhood). So the term `(d_omega[k] - some_local_mean)^2`
  appears ~3 times in the total local r_f sum, vs once in the
  global r_f sum. The local-means are not identical across
  neighborhoods, but they cluster around the global mean for any
  controller that has the system roughly synchronized, so the
  effective scaling is close to 3× (empirical 2.66×).

  This is a **structural property of the topology + reward formula**,
  not of the controllers. **Every controller** — symmetric (droop),
  RL-trained (any reward variant), passive (no-control) — sees the
  same 2.66× ratio. The R255 hypothesis that "RL converges to
  local-r_f-zero attractor that has nonzero global-r_f because
  ring-topology hides drift" is empirically refuted: there is no
  attractor where local-r_f differs from global-r_f by a
  controller-dependent amount.

  ### What the probe DOES reveal

  Looking at per-step r_f at the END of the trajectory (t=30.5 s):

  | Controller | last-step local r_f | last-step global r_f |
  |------------|---------------------|----------------------|
  | R201 hreg SOTA | -6.4e-09 | -2.4e-09 |
  | R254 phi_f-only | -4.2e-08 | -1.6e-08 |
  | R246 only-phi_abs | -5.6e-09 | -2.1e-09 |
  | Droop k=10 | -4.7e-11 | -1.7e-11 |
  | Droop k=2 | -2.8e-11 | -1.1e-11 |
  | No-control | -3.7e-08 | -1.4e-08 |

  **At trajectory end, all controllers (including no-control) achieve
  local-r_f near zero (1e-8 to 1e-11)** — i.e., the system fully
  synchronizes by 30 s regardless of controller. The cum_rf
  differences between controllers are dominated by the **transient
  phase** (first ~5-10 s), where the controllers shape how the
  system reaches synchronization.

  ### What CAUSES the RL cum_rf plateau (revised hypothesis)

  Since local-vs-global is not the answer, the cum_rf gap between
  RL SOTA (-0.069 LS1+LS2 sum) and droop k=10 (-0.037) reflects a
  **genuine performance gap in transient synchronization quality**.
  Candidate mechanisms (none verified):

  1. **Action-bound saturation**: RL actor outputs are normalized
     to [-1, 1] then projected to action range; if droop k=10 demands
     larger action magnitudes than RL outputs, RL is action-bounded.
  2. **Anticipation lack**: droop reacts to current Δf instantly via
     proportional control; RL must learn to anticipate, and may
     react slower in early transient.
  3. **Reward-shape trade-off**: RL trained with phi_f + phi_abs
     simultaneously optimizes both transient-Δf-reduction (phi_abs)
     and sync-tightness (phi_f). The Pareto-optimal balance for the
     combined reward may not coincide with the cum_rf-only optimum
     that droop k=10 occupies.
  4. **Network-coupling locality**: RL actors are per-agent (local
     observation); droop k=10 also per-agent but uses a simpler
     fixed-gain rule that exploits the network's frequency-coupling
     dynamics more directly.

  Hypotheses 1-2 are testable with another probe (no env change);
  hypothesis 3 requires retraining with different reward weights;
  hypothesis 4 requires architectural change (CTDE / global observation).

  ### Updated paper Sec.IV-D narrative implication

  The RL-vs-droop Pareto frontier (CLM-0445) is now **mechanistically
  cleaner**: no metric-mismatch loophole. The two controllers
  genuinely optimize for different objectives — droop k=10 directly
  minimizes per-step Δf sum; RL trades off Δf-sum against transient
  peak / settling / utilization (all 11-axis components). The
  Pareto frontier represents an **honest engineering trade-off**, not
  a metric artifact. This is the strongest possible framing.
