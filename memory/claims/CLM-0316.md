  **R166 — Research workflow asymmetry fix**. Adopted a 5-state round
  lifecycle (active / queued / completed / superseded / aborted) with
  `state` field on `RNNN/plan.md` frontmatter as the canonical source
  of truth (replacing the implicit "plan exists + no verdict = in-flight"
  heuristic). Closes 26 zombie rounds + 3 stale questions accumulated
  since R57 due to the asymmetric open/close cost in the prior workflow.

  ### Why this decision

  Prior workflow: `reserve_round.py` reserves a number atomically (cheap),
  but closing requires a full `verdict.md` (3 Q-sections + PI briefing,
  ADR-0003). When a round is superseded by later work, was queued and
  never fired, or was reserved by a parallel session race, the ceremony
  does not fit the actual exit path — so the round drifts in "in-flight"
  forever. STATE.md @ 09:56 showed 11 in-flight rounds; ~10:00 detected
  6 more empty reserved dirs from a parallel session writing R158/R160/
  R163/R165 verdicts. Total accumulated housekeeping debt = 26 rounds.

  ### What was done

  **Phase A — Tooling** (committed in this round):

  - `render.py` STATE.md `## In-Flight` replaced by `## 在跑 (state=active)`

  ### State semantics (forward contract)

  | state | meaning | verdict.md required |
  |-------|---------|---------------------|
  | active | truly in progress | no |
  | queued | reserved, waiting for slot | no |
  | completed | work done, conclusion drawn | yes (3 Q-sections + PI briefing) |
  | superseded | obsoleted by later round | no (only `superseded_by_round`) |
  | aborted | planned but won't execute | no (only `abort_reason`) |

  Terminal states are sticky. `superseded_by_round` must reference an
  existing round dir. validate.py enforces all these as hard rules.
