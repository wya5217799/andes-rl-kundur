  R110 disturbance-profile audit (zero compute, file inspection): ANDES
  default `andes/cases/kundur/kundur_full.xlsx` ships with a Toggler
  entry that trips Line_8 (Bus 8 → Bus 9, both Area 2 internal at 230 kV,
  one of two parallel paths) at simulation time t=2.0 s:

  ```json
  {"idx": 1, "u": 1.0, "name": "Toggler_1", "model": "Line",
   "dev": "Line_8", "t": 2.0}
  ```

  V4 env `_build_system()` (`src/andes_rl_kundur/env/andes/andes_vsg_env_v4.py`)
  does **NOT** remove or disable this Toggler. Grep "Toggler|trip|Line_8"
  across `src/` returns no matching mutation code.

  **Compound disturbance profile in every V4 LS1/LS2 scenario**:

  | t (s) | Event | Source |
  |---|---|---|
  | 0.0  | TDS warm-up starts | base_env.reset |
  | 0.5  | Load step ±2.48 / +1.88 pu | V4._apply_disturbance (paper) |
  | 0.7  | Agent control begins | agent loop |
  | **2.0**  | **Line_8 trip (Area 2 internal)** | **ANDES Toggler (UNINTENDED)** |
  | 10.5 | Agent control ends | STEPS_PER_EPISODE=50 |

  Paper §IV-C says LS1 / LS2 is a **single** load step (248 MW reduction
  at Bus 14, 188 MW increase at Bus 15). V4 evaluates with **load step
  AT t=0.5s + line trip AT t=2s** = compound disturbance scenario.

  **Likely missing piece of R08 Finding 2 / R09 2× residual** (CLM-0173):
  R89 audit identified F1 fn=60/50, F2 load topology, F3 D=0, F4 TGOV1
  active, F5 q0<0; F1 correction made residual *larger* not smaller.
  The Toggler-Line_8 trip is the F6 candidate to close the gap. Line
  trip adds frequency excursion + voltage transient ~at t=2s, which
  the max_df metric captures over the eval window. R110 hypothesis:
  Toggler removal would drop V4 no_ctrl max_df by ≥30% (Q-0025 quantifies).

  **Implication for R57-R85 91-round plateau** (CLM-0144):
  - All training + eval on compound scenario → trained policies learned
    to handle line trip + load step jointly
  - R72_w4 SOTA geo=0.391 is on compound scenario
  - R85 classical baseline best 0.197 is on compound scenario
  - Comparison RL vs classical (1.99× advantage CLM-0186) is still valid
    (same compound scenario for both)
  - But comparison vs paper Sec.IV-C is **NOT** apples-to-apples: paper
    is single-event, V4 is compound

  **R110 verdict + this claim are zero-compute audit deliverables.**
  Quantitative ablation (Toggler u=0 vs u=1, zero-action × LS1+LS2)
  deferred to Q-0025; cheapest path ~10 min wall once ANDES WSL slot
  is free (post-R83+R102+R85 cleanup).
