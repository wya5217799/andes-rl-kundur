  R145 focused multi-input magnitude-PD ceiling test (replaces R137
  killed by WSL reboot, 2 combos at D5-fair dm_max=600): **multi-input
  HURTS classical magnitude-PD, falsifying the "RL advantage from
  multi-input access" hypothesis**.

  | Controller | input set | geo | LS1 | LS2 | cum_rf |
  |---|---|---|---|---|---|
  | R102 baseline (P-only) | local \|Δω\| | **0.260** | 0.195 | 0.348 | -0.043 |
  | R145 plus_nM_nD | local + neighbor \|Δω\| | 0.219 | 0.164 | 0.294 | -0.045 |
  | R145 full | local + derivative + neighbor | **0.136** | 0.128 | 0.145 | -0.042 |
  | R72_w4 LSTM SOTA (CLM-0094) | full obs Eq.11 | 0.391 | — | — | — |

  Adding neighbor input degrades geo -16% (0.219 vs 0.260); adding
  derivative ON TOP degrades -48% (0.136 vs 0.260). **RL advantage
  GROWS, not shrinks, when classical is given more inputs**:
  - baseline (P-only): RL 1.50× advantage
  - plus_nM_nD: RL 1.78× advantage
  - full: RL 2.88× advantage

  **Mechanism**: 4 distributed magnitude-PD controllers receive the
  SAME neighbor frequency simultaneously. When neighbor Δω > 0, all
  4 agents simultaneously inject more inertia/damping → correlated
  over-injection → oscillation amplification. Derivative term spikes
  on transients, compounding the synchronised over-reaction.

  **cum_rf is nearly identical** across 3 controllers (-0.043, -0.045,
  -0.042) — they're doing similar net damping work, but waveform
  shape differs dramatically. **paper §IV-C cum_rf metric alone CANNOT
  detect the multi-input over-coordination problem** — only the 11-axis
  paper_grade_axes (max_df + settling + oscillation) catches it.
  This is independent evidence for the project's geo-vs-cum_rf
  framework choice (R57+).

  **Paper-narrative implication**: paper-mandatory classical baseline
  (`docs/paper/known_deviations_R85_to_R110.md` D4) should:
  1. Cite single-input mag-PD 0.260 as the "best classical"
  2. Cite R145 to show multi-input doesn't trivially close gap
  3. Frame RL contribution as **learned anti-correlated cross-agent
     coordination** (not just "RL uses neighbor info"). RL learns
     when to NOT add damping based on what neighbors are doing —
     a behavior fundamentally outside the linear-gain-combination
     classical control class.

  R72_w4 SOTA 1.50× advantage now strengthened: it's not just "RL
  uses more inputs", it's "RL learns the coordination policy that
  hand-tuned classical cannot construct from gain combinations". This
  closes a key paper-defensibility gap.
