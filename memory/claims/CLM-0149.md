statement: |
  R84-W2 produces the first **mechanism-level** evidence for the
  R57-R82 91-round algorithm-replacement plateau (CLM-0144): the
  R72_w4 LSTM SOTA critic exhibits monotone-in-action Q landscape
  with argmax saturating at action boundary ±1, while the actor
  outputs an interior a_sota ≠ argmax. This is a textbook
  actor-critic decoupling: the actor was trained against a critic
  whose gradient signal points to the boundary, but the policy
  gradient + target-network smoothing kept the policy interior —
  TD3 target-policy smoothing + tanh squash + warmup=5 (R72_w4
  hyper) together suppress boundary commitment. Implication for
  the R57-R82 plateau interpretation: the bottleneck is **not**
  algorithm class (SAC vs TD3 vs Transformer vs multi-layer LSTM
  all share the same TD-based critic-update paradigm) — it is the
  **critic representation** trained under paper-faithful obs (7-dim,
  no own-action no time-aug) failing to encode a concave action
  preference. R83 (obs space refactor, in-flight) could in principle
  fix this if richer obs let the critic learn a concave landscape;
  otherwise R85+ should test (a) different critic architectures
  (Q-distributional / IQN / quantile critic) or (b) explicit
  action-feature engineering (relative-action / log-action) —
  changes that perturb the critic's representation rather than the
  actor's. Caveat: synthetic obs prior result; ANDES-trajectory
  variant (Q-NEW) needed to confirm pathology on SOTA state manifold.
