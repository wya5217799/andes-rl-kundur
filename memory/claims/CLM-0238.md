  **Mechanism (CORRECTS CLM-0204's qualitative reading)**:

  CLM-0204 said "warm-h_0 introduces severe ΔM/ΔD non-smoothness which
  11-axis punishes". This is **wrong** — warm-h_0 smoothness scores are
  HIGHER than baseline (0.97-0.98 vs 0.24-0.69) because saturated-pinned
  actions don't oscillate.

  The actual killers are **utilization (axes 6, 7) + activity gate
  (axis 9)**. These axes use **range of action / range of paper action**:
  proj_dH_span = max(dH) - min(dH) where dH = H - H[0]. warm-h_0 starts

  dH ≈ 0 throughout → range 2.2 (vs paper 400) → utilization 0.6%.

  the geo. With dH, dD ≈ 0-5 throughout for all 4 agents, min activity =
  4.2 << threshold 50 → score 0.083.

  **Interpretation for paper Section IV-D**: the 11-axis geo metric is
  a "multi-faceted policy quality" measure where some axes reward
  physics (1-5) but others reward policy DYNAMICS / VARIATION (6-7
  utilization, 9 min_activity). A policy that's good on physics but
  extreme on dynamics (e.g., saturated constant pin) fails 11-axis
