  **R128 post-mortem of the R107-R126 warm-h_0 implementation track**.
  This session built up an R107 (CLM-0193 actor module) → R109 (CLM-0201
  agent class) → R117 (CLM-0217 hard ceiling) → R125 (CLM-0225 paper
  figure) → R126 (CLM-0229 h-locked-vs-geo) chain framing warm-h_0 as
  the Q-0022 fix. In parallel, R112 (CLM-0204, run by a concurrent
  session) directly tested the inference-time warm-h_0 variant on the
  real env:

  - **Q-side replication confirmed**: ‖a_step0‖ 10% → 99%, ΔQ +57% (R104).
  - **Env-side catastrophic**: 6-axis geo 0.391 → **0.017** (−95.8%).
  - **Paper-§IV-C cum_rf**: −0.068 → **−0.031** (+54% improvement).

  R112 closed Q-0022 closed-negative on the 6-axis metric. CLM-0193's
  trust was downgraded V→S. CLM-0207 (cross-algo step-0 deficit) was
  re-annotated as "phenomenological only — does not license a universal
  mechanism claim".

  **R128 housekeeping decisions**:

  1. **Keep code artefacts** (`networks_warmh0.py`,
     `td3_lstm_warmh0.py`, `test_warmh0_modules.py`). They are
     unit-tested, separate files, do not perturb any other code path.
     A future researcher who wants to revisit the warm-h_0 idea (e.g.
     for the **constrained α-interpolated** variant from CLM-0204
     R85+ list — scale ‖h*‖ down so step-0 ‖a‖ reaches ~50%, not 100%)
     can use these as drop-in components.

  2. **Keep train.py + checkpoint_loader.py dispatcher edits**:
     R128 added `--algo td3_lstm_warmh0` to the dispatch chain (line 88
     choices list, line 51 import). This is a 5-LOC addition matching
     the existing td3_lstm / td3_lstm_hreg / td3_qr_lstm pattern. The
     algo is now selectable but **not motivated by current evidence**
     for SOTA-targeted training. Document the closed-negative state
     in the algo's help string in a future cleanup round.

  3. **Mechanism CLM chain re-framed**: CLM-0174 / CLM-0188 / CLM-0193 /
     CLM-0207 / CLM-0212 / CLM-0217 / CLM-0225 retain their
     phenomenological / Q-side validity. They demonstrate:
     - A universal step-0 saturation deficit exists (Q-side)
     - That deficit is architectural (h=0 is the bottleneck, not obs)
     - A learnable h_init MLP can lift Q at step 0
     But they DO NOT support: "warm-h_0 lifts paper 6-axis geo above
     0.391". CLM-0204 refuted the joint claim. Paper Section IV-D
     narrative needs to lead with **the metric-divergence finding**
     (cum_rf vs geo anticorrelated at step-0 boundary) rather than the
     warm-h_0-as-fix angle.

  4. **R96 launch surface change**: prior CLMs (R109 CLM-0201,
     R117 CLM-0217 W2 tests, R125 CLM-0225 figure) called R96
     "implementation-ready / motivated / awaiting WSL slot". Re-classified
     to **"implementation-ready / DEMOTIVATED / available for
     constrained-α variant exploration"**. Default next-step train run
     should NOT be plain td3_lstm_warmh0 — should be either the
     **R85+ Constrained warm-h_0** (one extra α scaling hyperparam) or
     a fresh hypothesis from the R113 magnitude-randomised training
     direction.

  5. **CLM-0229 (R126 less h-locked = worse geo, N=2)** still stands as
     finding — independent of warm-h_0 path. Suggests SOTA learned
     "h carries history" not "h carries saturation trigger".

  This decision closes the warm-h_0 work I drove this session as a
  research direction, while preserving all infrastructure investments
  (code, tests, figure) for future follow-up.
