statement: |
  **Supersedes CLM-0157.** CLM-0157 decided R87+ priority is "perturb
  critic representation" (action feature engineering, distributional
  critic, spectral norm) based on R86 cross-ckpt synthetic-obs monotone
  Q evidence (CLM-0155). This decision is **withdrawn** by two pieces
  of subsequent evidence:

  1. **CLM-0160 (R84-W3-traj, on-manifold variant)**: the R72_w4 SOTA
     critic IS concave around a_sota on real ANDES TDS trajectory
     state distribution (advantage +120% of |Q|, argmax_dist 0.126).
     Synthetic-obs monotone is an artefact of probing the LSTM
     critic at h_critic=0 + obs ~ N(0, σ²I) — the LSTM hidden state
     carries the action-preference signal in regimes the critic
     actually operates in.

  2. **CLM-0161 (R88-W1, per-step phase breakdown)**: the on-manifold
     concavity is bimodal. Steady-state (step ≥ 10) has 2.5% bad-argmax
     fraction; transient (step 0-2) has 100% bad-argmax fraction +
     advantage only +14% of |Q|. The critic IS confused on the real
     manifold, but only in the immediate post-disturbance phase.

  **New R87+ priority (revised)**:
  - ❌ Action feature engineering — withdrawn. Adding [a, a², |a|]
    targets representation-side concavity which the critic already has
    in steady-state.
  - ❌ Distributional critic (IQN / QR head) — withdrawn (same reason
    as CLM-0160).
  - ❌ Critic spectral norm — withdrawn (CLM-0154 already showed
    spectral analysis healthy; CLM-0160 confirmed on-manifold).
  - ✅ **Transient-phase replay reweighting** — PROMOTED to candidate
    PRIORITY 1. Hypothesis: importance-weighted replay buffer toward
    early-step (step 0-5) samples breaks the 0.391 plateau by training
    the critic more on the regime where the 6-axis metric is dominated.
    Implementation: modify TD3 replay sampling to bias toward
    `step < 5` with weight 2-5×; train td3_lstm 75 ep on R72_w4
    hyper; eval 11-axis geo on LS1+LS2. ~30 min wall on WSL.
    Falsifies if reweighted run still ≤ 0.391.
  - ✅ **D3 obs sufficiency** (CLM-0160-promoted) — kept. Question
    is now: does obs+h_critic at step 0-2 carry enough info to
    decide between the 100 random actions, or is the obs ceiling
    binding? Cheap offline test using cached trajectory data.
  - ✅ **Curriculum / 2-stage training** (NEW) — alternative form:
    pre-train critic on "synthetic transient" data with rich action
    coverage before normal RL, then continue. Same hypothesis as
    replay reweighting but cleaner separation.

  Q-0019 (distributional critic test) status: **stay open** (not
  rejected by experiment, only deprioritised by superior mechanism
  evidence). Add log note pointing here.
