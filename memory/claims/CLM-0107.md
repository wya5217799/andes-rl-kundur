  R67 — **LSTM + Q-0007 + paper-metric mode is architecturally
  incompatible**: training collapses, eval = **-0.4763** (-145% vs SAC
  paper-faithful -0.194).

  ### W1a setup

  ```
  python scripts/train.py --algo td3_lstm --normalize-actions \
    --episodes 75 --seed 51 --hidden-size 64 --lstm-lr-warmup-eps 5 \
    --reward-config paper_strict_pure_radsec --eval-every-n-eps 5 \
    --save-dir results/r67_w1a_lstm_q7_paper_s51
  ```

  ### Eval result (paper-strict 20-scen test set)

  | suffix | total_cum_rf |
  |---|---|
  | best_eval | **-0.4763** |
  | best | -0.5750 |

  vs R65 SAC h=64 combo s51 (same paper_strict_pure_radsec eval) = -0.163
  → **W1a is 2.9× worse** in absolute cum_rf.

  ### Training pathology indicators

  - Reward trajectory: best @ ep 28 = -50 (SAC/TD3 R65 normal: -2 to -5)
  - TDS failures: 2/75 = 2.7% (SAC/TD3 R65 normal: 0/75)
  - Freq peak deviation: 0.36 Hz (R65 SAC: 0.10 Hz normal range)
  - Per-agent reward dispersion: a3=-18.7, a0=-244.4, a1=-246.3, a2=-245.9
    → only 1/4 agents (a3) learned, 3/4 collapsed
  - "Time step reduced to zero. Convergence is not likely" appeared ×2 mid-training

  ### Mechanism (hypothesis, not bisected)

  Three concurrent failures, each plausible:

  1. **LSTM hidden state + paper_strict reward shape mismatch**: paper-strict
     reward uses radsec scaling + pure cum_rf (no PHI smoothness term). LSTM
     BPTT through 25-step sequences accumulates gradient signal heavily
     weighted by terminal reward. Pure cum_rf reward gives weak per-step
     signal → LSTM hidden state drifts toward degenerate solution.

  2. **Q-0007 prospective probe with LSTM**: even with Q-0010 fix (CLM-0102),
     eval probe creates new ANDES env that resets paper_strict_pure_radsec
     config every 5 eps. The new env interacts with LSTM hidden state
     decoherently → training trajectory becomes non-stationary.

  3. **3/4 agent collapse**: V4 4-agent system normally trains with shared
     experience replay. LSTM uses per-agent replay (lstm_capacity=200 eps).
     Under paper_strict, only one agent (a3) found a viable policy; others
     diverged. This may be a multi-agent + LSTM interaction unrelated to
     paper-metric eval.

  ### Implication

  - **Q-0007 救命器 NOT universal**: works on SAC/TD3 +14-20% (CLM-0080),
    fails on LSTM-paper-metric -145%
  - **LSTM is paper-faithful-mode only**: viable in 6-axis ranker mode
    (CLM-0067 R57-α 0.543 SOTA) but NOT in paper-metric mode
  - **6-axis SOTA path remains LSTM**, paper-metric SOTA path remains
    TD3 (CLM-0105)

  ### What we tested vs what we didn't

  - ✓ LSTM + Q-0007 + paper-metric: -0.4763 (failed)
  - ✗ LSTM + Q-0007 + paper-faithful (without strict): not tested
  - ✗ LSTM without Q-0007 + paper-metric: not tested
  - ✗ Separating the 3 hypothesis causes: not done

  Deferred to R68+ if LSTM paper-metric becomes interesting.
