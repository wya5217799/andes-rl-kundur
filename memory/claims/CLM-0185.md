  R85-W2/W3 (PI scan, Phase 1 P-only 3×3 + Phase 2 Ki 2×2): naive
  distributed PI control on V4 paper-faithful Kundur catastrophically
  fails. Best PI `(Kp_M=2, Ki_M=2, Kp_D=10, Ki_D=10)` →
  **geo=0.0585 (LS1=0.0000, LS2=0.342)**, **WORSE than no_control 0.104**
  (R30). LS1 trace audit reveals **TDS divergence at step 33/150**
  (max_df=0.677 Hz, no_control LS1 max_df=0.189 Hz):

  ```
  step 1: dM = [-1.1, -2.9, -84.5, -3.1] (agent 2 saturates fast)
  step 2: dM = [-4.6, -10.5, -200.0, -11.4] (saturated → M clipped to M_MIN=20)
  step 32: freq oscillates, TDS divergence at step 33
  ```

  **Root cause (paper-worthy finding)**: signed PI law
  `ΔM_norm[i] = -Kp_M*err - Ki_M*∫err  where err = obs[i][1]`
  assumes setpoint-tracking semantics (error sign maps to control
  sign). LS1 disturbance (Bus 14 load reduction) → freq RISES → err > 0
  → PI sends ΔM_norm < 0 (REMOVE inertia), action saturates at -1
  → effective M ≈ 20 (vs M0=117 sys base), oscillation amplifies →
  TDS diverges.

  VSG parameter control is **magnitude-symmetric**: always add
  inertia/damping when |Δω| > 0, regardless of frequency direction.
  Correct law is `ΔM_norm = K * |err|` (NOT `-K * err`). My droop
  controller (CLM-0184) is already magnitude-based and works (geo
  0.197).

  **Paper interpretation**: this is NOT a "tuning failure" of PI — it
  is a paradigm-mismatch demonstration. Classical-control transplant
  (signed PI from setpoint tracking) fundamentally ill-fits VSG
  parameter modulation. RL learns magnitude-symmetric response
  implicitly without explicit prior; classical engineers need domain
  knowledge to write the right form. This supports paper Sec.IV-C's
  implicit "RL avoids classical-control assumption mismatch" claim
  with empirical evidence.

  R102 will implement magnitude-PI variant for completeness; even if
  it matches droop ~0.20, the naive-PI finding remains paper-worthy
  as the "naive transplant fails" demonstration.
