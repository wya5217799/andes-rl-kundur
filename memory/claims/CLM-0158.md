  ### Mechanism interpretation (3 候选, 未定论)

  R83 obs aug 全部失败的 mechanism 层解释**未定论**, 3 候选并存:

  **候选 1**: critic 沿 action 轴 monotone, argmax 在 boundary, actor-critic
  decoupled (R84-W2 CLM-0149 + R86 CLM-0155 universalised N=6 ckpt on
  synthetic prior obs). **改 obs 只改 critic input 表示, 不改 critic-actor
  argmax mismatch** (TD-based critic + tanh-bounded actor 范式结构性问题).
  **Caveat**: R84-W3-traj (CLM-0160) 在 ANDES on-manifold trajectory 上
  实测 critic 是 concave 不 monotone, refutes synthetic-obs mechanism story.
  obs aug 改变 prior 分布是否让 monotone 仍 universalize 未测.

  **候选 2**: R72_w4 narrow basin sensitivity (R81 9 wave 单 axis perturbation
  同 pattern, CLM-0142). obs aug 把 obs 分布从 R72_w4 训练分布 shift 出去,
  即使加 valid 信息也破坏 narrow basin → R83 W3 area_mean_freq -16% 是
  最极端版本.

  **候选 3**: paper §0.5 双约束让 obs aug 改不动 dD smoothness 维 (R79
  trade-off 同方向, CLM-0150). 6-axis ranker 重 dD smoothness, 任何让
  agent 输出 ΔD 震荡的 obs aug 都退化 — obs aug 改变控制信号路径但 reward
  shape 没变.
