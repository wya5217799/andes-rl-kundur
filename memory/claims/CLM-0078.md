  R61 — SAC HAWE on R58 strict_radsec ckpts UNDERPERFORMS single-seed
  best (CLM-0072 Mode paper-faithful) under paper metric.

  ### Setup

  - Actor pool: R58 `paper_strict_pure_radsec` SAC ckpts {s49, s50, s51}
  - Eval: R58 paper_strict_eval 20-scen test set
    (paper_strict_pure_radsec config, 50 steps, seed 42)
  - 5 ensemble configs evaluated

  ### Result

  | config | total_cum_rf | mean_cum_rf | anchor_LS1 | anchor_LS2 |
  |---|---|---|---|---|
  | **R58 SAC s50 single** | **-0.397** | -0.0198 | **-0.054** | -0.042 |
  | R58 SAC 3-seed mean | -0.518 | -0.0259 | — | — |
  | hawe_sac_mean (1/3 each) | -0.492 | -0.0246 | -0.098 | -0.043 |
  | hawe_sac_median (4-actor) | -0.460 | -0.0230 | -0.085 | -0.046 |
  | hawe_sac_s50_anchor (0.2/0.6/0.2) | -0.445 | -0.0223 | -0.076 | -0.043 |
  | **hawe_sac_top2_s50s51 (0/0.6/0.4)** | **-0.415** | -0.0207 | -0.069 | **-0.039** |
  | hawe_sac_top2_s50s49 (0.4/0.6/0) | -0.479 | -0.0240 | -0.085 | -0.048 |

  **All 5 HAWE configs underperform s50 single ckpt** (4.5 % to 24 %
  worse on total_cum_rf). Best HAWE = top2 s50+s51 weighted, but
  still -4.5 % vs s50 single. LS1 systematically hurt across all
  HAWE configs (s50 single -0.054 → HAWE best -0.069, +28 % more
  negative); LS2 marginally improved on best HAWE (-0.042 → -0.039,
  -7 %) but not enough to offset LS1 loss.

  ### Mechanism — skewed-pool ensemble penalty

  Pool: s50 (-0.397) is meaningfully stronger than s49 (-0.632) and
  s51 (-0.526). HAWE averaging pulls the action distribution toward
  weaker actors:
  - Uniform mean: -0.492 ≈ (−0.397 − 0.632 − 0.526) / 3 = -0.518
    (within 0.026)
  - s50-anchor (0.6 s50): -0.445, closer to s50 but still down

  **Generalizes R57-β / CLM-0066 HAWE-pool-skew finding**: when one
  actor dominates the pool, no weighted combination reaches the
  peak without zero-weighting all others (which is just the peak).

  ### Relative improvement vs no-control (paper-comparable)

  Using R60 CLM-0076 no-control baseline (LS1=-0.118, LS2=-0.097):

  | controller | LS1 imp | LS2 imp | mean |
  |---|---|---|---|
  | paper DDIC (paper SOTA, 2000 ep) | 58 % | 35 % | 46.5 % |
  | **SAC s50 single (75 ep)** | **54 %** | **57 %** | **55.5 %** |
  | HAWE top2 s50+s51 | 42 % | 60 % | 51.0 % |
  | HAWE mean | 17 % | 56 % | 36.4 % |

  **SAC s50 single remains the paper-faithful production candidate**
  for CLM-0072 Mode paper-faithful, beating paper DDIC by +9 % relative
  improvement. HAWE-SAC adds no value over s50 single — abandon as
  an ensemble path for this config.

  ### Implications for CLM-0072 / CLM-0067

  - **CLM-0072 Mode paper-faithful unchanged**: SAC s50 single
    (paper_strict_pure_radsec) remains the production candidate.
  - **CLM-0067 Mode B (HAWE-LSTM top2 = 0.501) still stands**: LSTM
    HAWE on R57 pool {s49, s51, s52, s53} works (CLM-0066). HAWE
    works when pool is less skewed (R57 ratio s49 0.333 : s51 0.526
    = 0.63 vs SAC pool s49 -0.632 : s50 -0.397 = 0.63 — but R57's
    SOTA s51 is balanced by 3 other healthy seeds, vs SAC's s50
    is balanced by only 2 others).
  - **Take-away**: HAWE viability is pool-balance dependent, not
    just policy-class dependent.

  ### What was NOT tested

    seeds.
  - HAWE with `best_eval.pt` ckpts (Q-0007). Future round can revisit
    after running training with `--eval-every-n-eps 5`.
