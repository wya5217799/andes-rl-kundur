  R98-W3 implements **TD3-AFE-LSTM** (CLM-0157(b) action-feature-engineered
  critic prototype): min-viable-diff fix for the CLM-0150 affine-Q
  pathology. Only the critic's **input feature** construction differs
  from ``TD3LSTMAgent``:

  - base:  critic eats ``[obs, action]``                  (obs_dim + A)
  - AFE:   critic eats ``[obs, a, a², |a|, sign(a)]``     (obs_dim + 4A)

  The ``a²`` feature alone breaks the d²Q/da² ≈ 0 pathology: with the
  bilinear LSTM-cell first layer, the critic now has a *linear pathway*
  to a quadratic feature, so concave-around-interior preference is
  expressible without architectural change. ``|a|`` adds saturation-
  magnitude awareness, ``sign(a)`` adds discrete boundary detection.

  **New files**:
  - ``src/andes_rl_kundur/agents/networks_critic_variants.py``
    (shared with CLM-0189) — ``_afe_features`` + ``RecurrentAfeQNetwork``
    + ``RecurrentAfeDoubleQCritic``, drop-in for ``RecurrentDoubleQCritic``
    with scalar Q output preserved.
  - ``src/andes_rl_kundur/agents/td3_afe_lstm.py`` —
    ``TD3AfeLstmAgent(TD3LSTMAgent)`` overrides ``__init__`` (replaces
    critic with AFE variant) and ``save`` (writes
    ``algo: "td3_afe_lstm"``). ``update`` is **inherited unchanged** —
    the AFE Q network has the same forward signature ``(obs, action,
    h_prev) → (q, h_new)`` as ``RecurrentQNetwork``, so the training
    loop works bit-for-bit.

  **Test verification** (``tests/test_critic_variants.py``, 22/22 pass):
  - AFE Q network input dim is ``obs_dim + 4*action_dim``; LSTMCell
    sized accordingly; forward returns scalar Q ``(B, 1)``
  - at ``a == 0``, ``_afe_features`` is exactly zero — no NaN/inf in
    Q output; obs path still propagates gradient
  - AFE double critic preserves the ``(q1, q2, h_new)`` interface
  - ``TD3AfeLstmAgent`` satisfies ``BaseAgent`` Protocol,
    ``is_recurrent=True``, ``algo_name="td3_afe_lstm"``
  - ``update()`` returns finite ``critic_loss`` + ``actor_loss``
    after 3 dummy episodes (no NaN/inf)
  - backprop populates **all 4 AFE blocks** of the critic LSTM
    ``weight_ih`` with nonzero gradient — proves each of
    ``[a, a², |a|, sign(a)]`` has a live training signal
  - ``save`` / ``load`` roundtrip identity across 20-step deterministic
    rollout (atol=1e-6)
  - checkpoint carries ``algo="td3_afe_lstm"``

  **Existing td3_lstm regression**: 15/15 pass unchanged.

  **Min-viable-diff** ordering claim (CLM-0157 said "(b) < (a) < (c) in
  code surface"): TD3-AFE-LSTM adds **~75 LoC** (1 short agent file +
  1 critic class in shared variants module + 1 test class). TD3-QR-LSTM
  adds ~230 LoC (full update rewrite). R98 implements both so R99+ can
  A/B them under identical V4 training conditions, but if compute
  budget forces a choice, AFE is the smaller swing.

  **Not yet trained**: same R83-gated condition as CLM-0189. Adding
  ``--algo td3_afe_lstm`` to the ``train.py`` dispatch table is a
  single-line change deferred to R99+.
