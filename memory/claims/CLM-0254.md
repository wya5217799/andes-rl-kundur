  ### Key finding: r74_w3 is the cleanest paper SOTA

  **r74_w3 strictly dominates R72_w4**:
  - geo +5% (0.410 vs 0.391)
  - cum_rf identical (-0.068 = -0.068)

  This is **strict Pareto dominance** — no metric trade-off. r74_w3
  should be the project SOTA going forward.

  r75_baseline / r75_w2_s59 has higher geo (+10% vs R72_w4) but worse
  cum_rf (-10%, -0.075 vs -0.068). This is a real Pareto trade — not
  strict dominance. Acceptable if paper headline is geo; not if
  headline is cum_rf.

  Both r67_w2a (trained TD3-MLP) and warm-h_0 inference cluster at
  (geo ≈ 0.017-0.028, cum_rf ≈ -0.031). They're in a completely
  different basin from the LSTM SOTA cluster (geo ≈ 0.39-0.43, cum_rf
  ≈ -0.068). The cluster gap of (geo +0.37, cum_rf -0.04) shows the
  trade-off is **discrete** (attractor-class transitions) rather than
  continuous (smooth Pareto curve along an a-priori knob).
