statement: |
  R71 — paper_grade_axes upgraded **v3.0 → v3.1**: multiplicative gating
  aggregation replaces geo_mean to prevent dilution of gating axes.

  ### Aggregation change

  v3.0: `overall = geo_mean(11 axes)` (continuous + gating mixed)
  v3.1: `overall = geo_mean(axes 1-8) × min(axes 9, 10, 11)` (separated)

  ### Motivation

  R70 showed v3.0 ranks R69 W3 s50 (v3=0.5474) above R68 W2 s51 (v3=0.5329)
  despite R69 W3 having worse P_balance (0.56 vs 0.85). Paper-figure intuition
  disagreed: R68 W2 is clearly cleaner 4-agent collab. Source: v3.0 geo_mean
  treats P_balance=0.56 as same weight as max_df=0.9 — strong axes dilute
  gating penalty.

  v3.1 makes any single gating axis a multiplicative cap. R68 W2 s51 climbs
  from #3 to #1; R69 W1 s51 (P_bal=0.19) drops from #2 to #10; R57-α
  historical crashes from 0.4937 to 0.0618.

  ### Test results

  - 5 new v3.1 unit tests (synthetic + real-fixture)
  - 16 v3 unit tests still pass
  - 150 regression tests still pass
  - **21/21 v3+v3.1 tests pass total**

  - v3.0: 2026-05-18 R69 (axes 9-11)
  - **v3.1: 2026-05-18 R71 (multiplicative gating)** ← this claim

  ### Backward compatibility

  `enable_v3_axes=False` still uses plain geo_mean (v2.x behaviour).
  v3.0 score reproducible by computing both manually (not exposed in
  default path).
