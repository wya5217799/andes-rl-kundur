# R283 execution amendment — 分支有效性判定器 (2026-07-29)

**Precedent**: R281 execution_amendment_20260729.md (守卫阈值修正 + 识别规则
修订; plant 与数据口径未变). 本修正案同为分析层声明, 不改 plant / 不改数据.

## 触发

plan.md 契约第 4 条预注册了 "识别失败记 flag, 该点排除出梯度判定", 但未指定
**检测器**. R281 识别规则 (max |P_a1−P_a2|) 在 [0.2,1.5] Hz 内只要存在模态
就必然返回一个 — 分支串线时也会返回一个 (实测: M0=150/q=−0.25 给出
ζ=0.653, area_contrast≈0.0000, 物理上不可能是区间模态). 没有显式判定器,
"识别失败" 无法落地.

## 声明的判定器 (probes/r283_branch_analysis.py, 读 sealed summary.json)

1. **跨级 q=0 链**: 参与向量余弦 ≥ 0.9 (只查余弦, 不查频率 — 强度级改变
   惯量/联络电抗, 频率漂移是物理的; 实测漂移 M0 轴 0.509–0.579 Hz, k 轴
   0.470–0.559 Hz). 链的锚 = 锚点验证行 (M0=200 / k=1.0, |Δζ|<1e-6 复现
   R281), 传递性成立.
2. **级内端点**: q=±0.25 各自对该级 q=0 (跨级验证过的参考点) 判
   余弦 ≥ 0.9 **且** |Δf| < 0.05 Hz (R282 冻结标准; 同级内惯量/电抗不变,
   频率漂移应小 — R281/R282 全 q 范围实测 |Δf| ≤ 0.003 Hz).
3. 任一端点不过 → 识别失败 flag, 该级 S 不可测量, 排除出梯度判定.

## 边界

- 识别规则本身**未改** (仍 max |P_a1−P_a2|, 未在结果上重调) — 本判定器是
  结果的有效性筛, 不是新识别规则.
- 判定标准来自 R282 已冻结的连续性度量, 唯一新增是 "跨级频率漂移合法"
  的显式声明.
- 适用结果: M0=100/q=−0.25 flag (余弦 0.0000, |Δf|=0.186 Hz — 复现 R281
  的离线断点, 现在脚本内可复现); M0=150/q=±0.25 flag (hybridization 区,
  q=−0.25 处 area_contrast≈0). 其余 21 点全连续.
