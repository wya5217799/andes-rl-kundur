## Anti-patterns / gotchas (still true)

- **ANDES = WSL only**. `wsl bash -c "/home/wya/andes_venv/bin/python ..."`
  (NOT `wsl -e python` — Git Bash path translation breaks it).
- **Max 3 parallel WSL python processes**. R23 hard limit. 4+ →
  TDS internal-stiffness mis-judge.
- **Python `print` is block-buffered to log files**. Use
  `--log-interval N` so something flushes periodically. Real-time
  progress requires `PYTHONUNBUFFERED=1` or `python -u`.
- **`agent_*_best.pt` updates during training**. Eval scripts can
  read it mid-training; the final value is only stable after the
  process exits.
- **Train results NOT in git** — `results/*` is gitignored except
  `results/whitelist/`. Reproduce by re-running.
- **TD3 vs SAC ckpt schema differ**. `scripts/eval_ddic.py` auto-
  detects via the `algo` field in the ckpt. New algorithms should
  set `algo: <name>` in their save dict.
- **V4 default is paper-bit-identical** (`zero_g4_inertia=True`,
  `action_penalty_mode="physical"`). The new "normalized" mode is
  opt-in for research; default preserves R21 / HAWE / no_control
  reproducibility.
