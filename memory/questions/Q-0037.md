## Why it matters

R274 establishes that the frozen bounded droop+PI storage layer has valid
common-frequency-restoration authority on a prospectively screened signed,
multi-location bank.  R270/R271 separately showed that M/D changes can shape
transients but cannot provide sustained nominal-frequency restoration in the
current proxy.  The remaining Gate-2 question is therefore whether a fast M/D
layer contributes independent transient value once the slow active-power
restoration layer is already present.

This gate must precede residual learning.  If a bounded fast law cannot improve
RoCoF, peak frequency, synchronization, or inter-area oscillation beyond the
same slow controller with frozen M/D, the programme should remove the
multi-timescale fast-layer story rather than preserve complexity for its own
sake.

## Pre-commitment for the next round

1. Reuse the R274 feasible bank, storage plant, droop+PI gains, power/energy
   limits, solver, horizon, physical-frequency basis, and failure-retention
   contract without tuning on formal endpoints.
2. Keep the validated slow active-power controller identical in both arms.
   Compare fixed M/D=200/100 against exactly one prospectively specified,
   bounded fast M/D law selected using development-only evidence.
3. Freeze M/D amplitude/rate/action budgets and source hashes before formal
   trajectories.  Report M/D action L1/TV and any projection activation.
4. Use physical RoCoF, worst-bus peak, synchronization loss, and an explicit
   inter-area-oscillation endpoint as registered fast-layer outcomes.
   Common-frequency restoration, completion, storage SOC/power/energy, and
   constraint counts are mandatory guards.
5. Retain every failed trajectory and use paired uncertainty and tail risk.
   Do not train RL/GNN, change topology, alter the storage actuator, or claim a
   unified GFM-BESS.
6. If no independent fast-layer value survives the joint gate, remove the
   fast-layer branch and continue, if warranted, with the slow classical layer
   only.

## Decision direction

- **FAST-LAYER-POSITIVE:** the valid sealed comparison clears the registered
  fast transient endpoints and all slow-restoration, completion, action,
  energy, and safety guards.
- **FAST-LAYER-PARTIAL:** the experiment is valid but only a subset of the
  registered transient endpoints clears its materiality/uncertainty gate.
- **NO-INDEPENDENT-FAST-VALUE:** the valid comparison finds no material
  independent fast-layer margin; delete the dual-layer claim.
- **INVALID:** provenance, completion, endpoint, action-budget, or physical
  contract guards fail.
