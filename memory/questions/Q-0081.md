## Why it matters

R327 closes Q-0080 positive for numerical solver adequacy but rejects the
unchanged controller on valid development evidence: both retained-cross and
cross-deleted arms amplify the registered regulated-output metric relative to
zero control. Retaining measured cross blocks is less harmful than deleting
them, so hard decoupling is not the repair. Before changing weights, horizons,
or algorithms, the project must identify which causal link fails between state
estimation, chosen action, predicted response, and realized reduced-model
response.

## Candidates

- Use development cases only and keep the R327 solver, models, action limits,
  and controller settings fixed. Preserve the conditional holdout and every
  physical, distributed-agent, reward, and training block.
- First run a one-step identity audit on the worst valid cases: record the true
  reduced state, corrected estimate, candidate action, predicted next output,
  realized next output, constraint activity, and sign of the zero-control
  versus controlled output change. This can expose action-map, sign, timing,
  prediction, or estimator mismatch without a controller redesign.
- If the one-step map is correct, compare the existing estimated-state action
  with a true-state diagnostic action under the same objective and constraints.
  This isolates estimation from finite-horizon control without tuning either.
- Only if estimation is not dominant may a later prospective repair test one
  theory-backed terminal or horizon change. Do not run a weight grid, horizon
  sweep, agent, neural controller, or fresh holdout in the diagnosis.
