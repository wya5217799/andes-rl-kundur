## Why it matters

R82-W1 TD3Transformer 75 ep s54 smoke training OK (best reward -6 @ ep 21
跟 baseline LSTM 同量级, critic_loss 0.516→0.130 单调降), 但 deterministic
eval geo=0.010 (LS1=LS2=0 完全失能, 见 CLM-0145).

Root cause = TransformerActor maintains K=10 rolling obs window. episode
reset 时 window 全 0. 前 K=10 步看到 [zero pad × (K-1), real obs × (k+1)]
的 sparse context, causal self-attention 对 dominant zero tokens attend,
deterministic mode 输出 near-constant action. 50-step episode 里前 10 步
(=20%) 失控.

LSTM 通过 hidden state evolution 自然 escape (hidden 在 mid-episode 携带
有效信号, 不被 episode reset to zero), Transformer rolling window 没有
同等 escape mechanism.

如果修, Transformer architecture 可能在同样 75 ep budget 下达 baseline 同
量级, 测验 "novel architecture 是否真有杠杆". 但 91 round-level evidence
(R57-R82) 已经证明 plateau 是 problem setup 决定的, 即便修了 transformer
也不一定能突破 0.391. 所以这个 Q 优先级中等, 等 R83+ obs/multi-agent
路径有信号再回来.

## Candidates (修复路径)

- **A1** (~半天 code): burn-in 用 first-real-obs replication fill 而非 zero.
  init_hidden 改成: 首次 forward 时把 obs 复制 K 份做 init window. 这跟
  人类专家在新环境前几步 "假设 history = 当前 obs" 的合理 prior 一致.

- **A2** (~半天 code): 学一个 [BOS]-style learned padding token. obs_dim
  维度的 learnable parameter 作为初始 fill. 优势: 模型能学到 "这是 episode
  start" 的 signal, 区别真 obs / 假 pad. 劣势: 参数 +obs_dim 个.

- **A3** (~半天 code): attention mask 跳过 zero-pad positions. 模型只 attend
  real obs tokens. 简单实现 = TransformerEncoderLayer.forward 加 key_padding_mask.
  劣势: 第 1 步整个 attention vacuous (没 token 可 attend).

- **A4** (combo): A1 + A3 — 用 obs replication fill 之外, 第 k 步仅 attend
  positions [-k:]. 多数 production transformer 是这样.
