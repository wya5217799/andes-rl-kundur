6-axis geo = **0.391 / 0.381** (Δ=-0.94%, C4 negative finding). 加上 R80
grill cross-reference 历史:

R80 已经证否 "plant 风机颗粒度 = 瓶颈" (CLM-0141). 真正瓶颈两个候选:
- **(A) 算法侧**: SAC + 4-agent + 7-dim obs + 当前 reward 设计的能力上限
- **(B) 系统参数**: line / load / SBASE / solver mismatch

按 R80 grill 判断 (A) 优先 — RL paper 本职是算法, 不是 power system audit;
(A) 解决能直接出 paper-quality result, (B) 解决还得 (A) 才出 result.

Q-0014 = (A) 路径的入口.
