## Why it matters

R308 isolated the numerical contract further: `tol=1e-10` drove every sampled
post-control-step algebraic residual below the unchanged `1e-8` gate, but the
same tolerance was also consumed by ANDES' initialization self-test and made
both records retain exit code 1. A valid model-first path needs separate,
explicit acceptance semantics for initialization and dynamic Newton steps
before the signed authority bank can be rerun or interpreted.

## Candidates

- Preserve ANDES' default `1e-4` tolerance through PFlow and the 0.5-s TDS
  initialization, require `TDS.test_ok is True` and exit code zero, then switch
  exactly once to the already frozen `1e-10` dynamic correction tolerance and
  synchronized `tol_zero=1e-16` before the first controlled step.
- Repeat only OP1 zero and OP1 edge-2 negative with the unchanged 0.05
  system-p.u. pulse, five active samples, twenty recovery samples, and
  `max(abs(g)) <= 1e-8` sampled gate.
- Record initialization and dynamic solver settings separately and fail closed
  on any transition, exit, timing, input, structural, or residual mismatch.
- If this canary passes, authorize a separate fresh full Stage-1 round. If it
  fails, stop the current solver-repair path.
