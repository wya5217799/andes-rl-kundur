## Why it matters

R391/CLM-1100 establishes that the exact initialized ANDES 2.0.0 four-stock-
REGF2 reduced model contains two reproducible positive-real local modes
(+46.4153 s^-1 leading, +4.6068 s^-1 second) before any simulation time
advances. Participation associates the leading mode almost entirely with REGF2
states (virtual angle, active-power signal, active-power sensing, VSM speed
integrator) and the second mode with the d-axis outer-voltage PI integrator.
Participation is association, not causality. This mechanism question asks the
smallest upstream diagnostic that can attribute each mode to a concrete
installed parameter or feedback path, using one-variable-at-a-time
perturbation arms and the same no-time-advance EIG gate. It does not reopen
authority, control, learning, or any successor-object work.

## Prospective contract

- Keep ANDES 2.0.0, the packaged and derived Kundur static cases, 10-bus and
  15-line connectivity, four controlled locations, stock REGF2/PLL2 object
  ownership, and every explicit model parameter identical to R389/R391 in the
  reference arm. Bind all installed source and case hashes independently.
- Run one ordered bank of fresh serial arms, each built once, with no
  `TDS.run()`, action, controller, disturbance, reward, or training call.
  The reference arm A0 repeats the R391 `r389_reference_tol_1e-4` arm and
  must reproduce its two material roots within the frozen tolerance.
- Perturbation arms change exactly one explicit parameter each, applied after
  object construction and before `system.setup()`, everything else
  identical: H1a `mf` x4, H1b `mf` /4; H2a `Tpm` x10, H2b `Tr` x10;
  H3a `KIv` x4, H3b `KIv` /4; H4 `Sn` 900 -> 100 MVA.
- Every arm must pass the R391 integrity, equilibrium, finite-value,
  eigenpair-error, conditioning, catalog, and name guards. A perturbation arm
  that fails power flow, initialization, or a finite guard is a typed per-arm
  scientific stop, not record invalidity.
- Classify per frozen prediction: an arm family "carries" a material root when
  its leading-root real part moves by more than the frozen 10% relative
  threshold, or the material positive-real mode count above 1e-7 changes.
  One-variable sensitivity is a necessary-consistency attribution, not a
  counterfactual removal proof.
- A valid bank may close Q-0109 with a bounded mechanism attribution or an
  explicit no-isolated-parameter result. Neither outcome repairs R389,
  reopens the stock-REGF2 route, or authorizes authority, controller,
  learning, EMT, HIL, or deployment work.
