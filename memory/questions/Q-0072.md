## Why it matters

R316 validates a bounded order-10 dynamic surrogate on two small-signal
operating conditions, but it does not establish that any controller is
well-posed, constraint-compatible, robust to the measured mismatch, or better
than a matched non-decoupling baseline. A deterministic controller must close
those questions before distributed agents, residual learning, or MARL can be
scientifically identifiable.

## Candidates

- Freeze one deterministic synthesis objective on the retained-cross order-10
  realization, including sampling, state estimate, actuator map, rate/power/SOC
  constraints, common/differential weights, and use of the R316 empirical
  mismatch envelope.
- Compare it to one matched deterministic baseline with the same information,
  action authority, constraints, horizon, and tuning budget; isolate exactly
  one load-bearing structural difference.
- Use development-only model calculations and offline closed-loop diagnostics
  first. Reject the candidate before ANDES if nominal poles, constraint
  feasibility, mismatch stress, or comparison identifiability fail.
- If and only if the offline gate passes, pre-register a fresh physical
  closed-loop disturbance bank, metrics, no-harm guards, and a one-shot abort
  rule in a separate round.
- Stop before distributed runtime, reward design, neural residuals, or MARL.
