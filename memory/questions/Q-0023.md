## Why it matters
The whole point of NOTE-NNNN entries is to make legacy archives discoverable
without manual archaeology. If subsequent rounds don't query `note_query.py`
or cite a note's Key Fact as `extracted_from: NOTE-NNNN`, the index is
write-only — same failure mode as pre-R39 handoffs.

## Candidates
- Observation: count claims authored in rounds R99+ that carry an
  `extracted_from: NOTE-NNNN` provenance line.
- Negative observation: count rounds R99+ whose plan.md references a topic
  that has notes, but the verdict never cited the note.
