## Why it matters

R270 found that an outcome-seeing M/D library oracle materially improved
synchronization, peak deviation, and RoCoF but improved physical VSG-mean IAE
by only 0.311%.  R271 then showed from the implemented equations and immutable
traces that the current four `PV+GENCLS` proxies have no independent power
setpoint, SOC, energy, or headroom state for sustained restoration.

The next uncertainty is therefore an actuator-authority question, not an
algorithm question.  Before building a unified GFM-BESS, training a residual
policy, or discussing topology generalisation, the programme must test whether
a separately controlled but physically bounded storage-power channel produces
a material and repeatable common-frequency-restoration margin at all.

## Pre-commitment for R272

1. Use the minimum-reuse hybrid proxy only: preserve the current four
   `PV+GENCLS` VSG proxies and add independent `ESD1` storage devices through
   the actual `DG.set_paux()` active-power interface.  Describe this honestly
   as a VSG proxy plus GFL BESS, not a unified GFM-BESS.
2. Source and freeze device power, energy, SOC, headroom, efficiency,
   charge/discharge, lag, ramp, and converter-capability limits before any new
   real-ANDES trajectory.  Record every physical-to-per-unit derivation and
   hash the resulting contract.
3. Keep the current M/D settings fixed.  On development disturbances only,
   compare identical-DAE zero support, P-f droop, and droop plus PI/AGC;
   constrained MPC remains dormant unless a later question authorizes it.
   Freeze exactly one primary classical controller before opening a new
   no-anchor sealed bank.
4. The formal co-primary endpoints are full-horizon physical VSG-mean IAE and
   final-window common-frequency absolute mean.  Both must improve by at least
   2% with a paired-bootstrap upper confidence bound below zero.
   The primary matched baseline contains the identical ESD1 DAE structure but
   commands zero active-power support; the original V4 system without ESD1 is
   a secondary structural contrast only.  This prospective correction follows
   a test-first finding that zero-command ESD1 states change the first VSG
   frequency sample by up to about 2.16e-4 Hz.
5. Completion/failure, normalized synchronization loss, worst-bus peak,
   sampled RoCoF, action L1/TV, saturation, SOC, energy, power, ramp, and
   capability constraints are mandatory guards.  Failed trajectories remain
   in the denominator.
6. No RL, GNN, topology generalisation, stability certificate,
   cross-simulator/HIL claim, or manuscript work is authorized in this
   question.

## Decision direction

- **AUTHORITY-POSITIVE:** both co-primary endpoints and every mandatory guard
  pass.  Only this result may open Gate 2, which asks whether the frozen fast
  M/D layer adds independent transient value under the same slow controller.
- **AUTHORITY-PARTIAL:** restoration improves but misses a co-primary
  materiality, uncertainty, or guard requirement.  Diagnose the exact
  physical/controller limitation without opening learning work.
- **NO-MATERIAL-AUTHORITY:** a valid frozen classical actuator does not create
  the registered margin.  Close this contract rather than increasing model or
  algorithm complexity post hoc.
- **INVALID:** initialization, interface, unit, energy-accounting, numerical,
  or provenance checks fail.  Repair correctness only; do not interpret
  performance.
