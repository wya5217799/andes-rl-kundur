## Why it matters

R268 demonstrated that the bounded residual software path is correct and
executable, but the learned controller failed both co-primary physical mean
directions.  The strongest concrete mismatch is structural: the frozen V4
reward has `PHI_ABS=0`, so it does not train common-mode/absolute frequency
restoration, while the decision gate requires VSG-mean IAE to improve.  The
existing inertia/damping regularizers also score averages of executed action,
not the learned residual's own magnitude and temporal variation.

A second controller training run is not informative until its optimization
objective is demonstrably aligned with the physical endpoint vector used to
judge success.  This question is an objective/interface audit, not a new
algorithm search.

## Pre-commitment for the future round

1. Begin with the existing R268 traces, reward implementation, physical
   endpoint summarizer, and residual adapter; run no new ANDES trajectory and
   no training while the objective contract is being selected.
2. Express common-mode frequency restoration, differential synchronization,
   residual magnitude, and residual temporal variation in explicit physical
   or normalized units.  Keep safety/failure as constraints or guards rather
   than hiding them inside an opaque composite.
3. Ensure the residual-specific penalty is zero for the zero-residual droop
   reference and cannot be reduced by opposing per-agent residuals that cancel
   only in the fleet average.
4. Add synthetic sign/unit tests and archived-trace ranking checks that would
   fail for the R268 mismatch.  Freeze one objective contract before any new
   training; do not choose weights from its future evaluation bank.
5. Keep TD3 versus SAC, hidden-size, seed, horizon, residual-scale, topology,
   graph architecture, stability certification, cross-simulator validation,
   and manuscript work out of the objective-audit stage.

## Decision direction

- Advance to one new residual pilot only if the objective passes unit/sign
  tests, distinguishes common and differential frequency modes, assigns
  residual-specific effort/variation correctly, and ranks controlled
  trajectory perturbations consistently with the predeclared physical
  endpoint directions.
- If no simple auditable objective can pass those checks without post-hoc
  weight selection, close the learned residual programme on this environment
  and pivot the project to a benchmark/diagnostic contribution rather than
  another controller architecture.
- A passed objective audit is not evidence that a learned controller works; it
  only authorizes a separately pre-registered training experiment.
