## Why it matters

R276 found no material non-additive fast/slow interaction, so coordination
complexity by itself cannot justify MARL. The R274+R275 combination is still a
strong additive classical controller: slow bounded active power supplies
restoration, while the frozen common-inertia pulse supplies transient value.
Before training Q-0038, the programme needs a deliberately optimistic upper
bound on the only remaining proposed learned action: a small zero-sum spatial
redistribution of inertia around that fixed common pulse.

If an outcome-seeing finite-library oracle cannot materially improve both
registered differential endpoints without harming common-mode, restoration,
completion, storage, action, and tail guards, parallel multi-seed MARL
training has no validated target and should not run.

## Pre-commitment for the next round

1. Reuse the immutable R275 combined traces and exact R274 formal 24-scenario
   bank, plant, slow controller, common pulse, solver, horizon, physical
   endpoints, and storage/action contracts by hash.
2. Add only the six signed zero-sum Hadamard inertia directions spanning the
   three-dimensional four-agent zero-sum subspace. Each direction is active
   for the same first 15 steps and is composed around the unchanged +0.25
   common-inertia pulse with one frozen differential amplitude.
3. Let an explicitly outcome-seeing development oracle choose among the six
   candidates and the reused baseline separately for each scenario. Treat it
   only as an optimistic attainable-margin diagnosis, never as a deployable
   controller or paper result.
4. Require material improvement on both synchronization loss and first-3-s
   inter-area IAE with paired uncertainty, while guarding RoCoF, peak,
   full-horizon/final-window restoration, completion, action, storage, SOC,
   power, energy, constraints, tail risk, and provenance.
5. Run exactly 144 new trajectories in eight disjoint WSL shards if the
   measured preflight confirms the current 16-core/32-thread, 24-GiB WSL host
   remains below CPU and memory limits. Do not train neural policies.
6. If the optimistic oracle has no material guarded margin, close or abandon
   Q-0038 as `NO-RL-NEEDED`. If it has a reproducible margin, freeze that
   single gap before authorizing parallel multi-seed residual training.

## Decision direction

- **LEARNING-GAP-PRESENT:** the optimistic oracle materially improves both
  registered differential endpoints with uncertainty support and every
  common-mode, restoration, action, storage, tail, completion, and provenance
  guard passes.
- **LEARNING-GAP-PARTIAL:** only one differential endpoint clears, or the
  margin is material only on a registered subset, without guarded harm.
- **NO-RL-NEEDED:** the valid optimistic oracle cannot clear the joint
  differential gate; do not train Q-0038 on this fixed topology.
- **INVALID:** any source, seal, trace, completion, action, storage, endpoint,
  oracle-selection, or provenance contract fails.
