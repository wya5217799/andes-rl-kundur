## Why it matters

R280 identified learned value only in a centrally aggregated scalar
coordinate, while R292 implemented genuine neighbour-edge decentralized
execution but mixed controller efficacy and no-harm failures into an
`INVALID` matrix. Neither result supports a broad centralized-versus-
distributed architecture conclusion. The new comparison must use a credible
classical distributed controller, matched vector action authority, and a
valid negative-result path.

## Pre-commitment

1. Retain the validated slow droop--PI storage layer and fixed common-inertia
   pulse as the strong common-mode classical base for every arm.
2. Develop one causal neighbour-only edge controller that transfers inertia
   toward the endpoint with greater locally measured transient severity. Its
   feature families, gains, selection bank, guard bank, action limits, and
   stopping rule are frozen before controller evaluation.
3. Use the selected causal edge controller as the identical prior for both
   learned residual arms. The distributed actor sees only edge-endpoint
   observations; the centralized actor sees the joint observation. Both emit
   the same three oriented edge coordinates and use matched optimization,
   seeds, interaction budget, and safety projection.
4. Keep evidence-integrity validity separate from efficacy, non-inferiority,
   and no-harm outcomes. A completed, correctly executed poor arm is negative
   evidence, not an integrity failure.
5. Freeze all controllers before generating a fresh signed multi-location
   formal bank. Retain every seed, scenario, failure, and guard outcome.
6. Attribute only the executed objects. Parameter sharing is allowed, but no
   scalar vote aggregation, centralized action projection, four-independent-
   device claim, generic MARL claim, or deployment claim is allowed.

## Decision direction

- **DISTRIBUTED-SUPERIOR:** the distributed residual materially beats the
  causal edge controller and centralized residual on both co-primary
  endpoints with all registered positive-claim guards.
- **DISTRIBUTED-NONINFERIOR-LOCAL:** the distributed residual materially beats
  the causal edge controller and stays within the frozen non-inferiority
  margin against centralized residual on both co-primary endpoints, while
  requiring no joint-observation action server.
- **CENTRALIZED-SUPERIOR:** the centralized residual has guarded incremental
  value and the distributed residual is inferior beyond the frozen margin.
- **NO-NEURAL-INCREMENT:** neither learned residual has reproducible value over
  the tuned causal edge controller.
- **CLASSICAL-FAMILY-NO-GO:** the prospectively bounded causal edge family
  cannot produce a credible guarded comparator in the declared action space.
- **INTEGRITY-INVALID:** seal, provenance, completion, action, budget, or
  statistical implementation contracts fail. Efficacy and no-harm failures
  alone do not trigger this class.
