## Why it matters

R37 surfaced a silent V2-inheritance bug (CLM-0040): every paper-cited
6-axis headline number was computed with `ZERO_G4_INERTIA=True` despite
V4's docstring claiming "G4 inertia preserved":

- R21 lucky single seed = 0.444 (CLM-0005)
- HAWE w9802 reproducible = 0.439 (CLM-0007)
- HAWE w8515 = 0.415 (CLM-0006)
- no_control baseline = 0.104 (CLM-0008)
- SAC multi-seed attractor = 0.137 ± 0.005

R37 chose to pin `True` explicitly to preserve bit-identical
reproducibility of the published headline. This Question decides
whether a future round should run the paper-faithful variant
(`ZERO_G4_INERTIA=False`) and report whether the ranking changes.

R15 forensic baseline noted "G4 preserved drops max_df 26%" under the
old V1/V2 reward and H₀, but never under V4's H₀=100 + φ rescale +
paper-faithful action range. The cross-effect with R38's reward-
landscape finding (CLM-0043 — action cost dominates frequency cost
by 500–1000×) is unknown.

## Candidates

- **no_control rerun (cheapest, ~5 min)**: rerun the no-control
  baseline with `ZERO_G4_INERTIA=False`; compare max_df / cum_rf /
  6-axis vs 0.104. If 6-axis stays in [0.09, 0.12], headline ranking
  is robust to G4 — answer is closed-negative on changing the headline.
- **R21 single-seed rerun (~30 min)**: rerun V4_h50_s49 single
  evaluation with G4 preserved; if 6-axis still > HAWE w9802 score on
  the SAME G4-preserved baseline, headline ranking preserved.
- **22-ckpt H₀ sweep subset rerun**: too expensive (~6 h × 4 seeds);
  defer until candidates 1 + 2 give a directional answer.
- **Full headline regeneration**: only if candidate 2 shows R21 drops
  below HAWE — would require paper revision.
