## Why it matters

R317 validly rejected both versions of one delayed DC-inverse static law before
the conditional examination, but its result artifact intentionally records
only that no feasible scalar was selected. A bounded diagnostic must separate
nominal pole rejection from governed-development rejection before a new
controller form is chosen. Otherwise a gain-grid expansion could hide the
structural timing problem in post-outcome tuning.

## Candidates

- Replay the already frozen 100-scalar grid with no new optimization, physical
  data, or threshold change and record, for each arm, the augmented-pole radius
  and whether the governed development calculation was reached.
- If all candidates fail the pole gate, derive one preconditioned or leaky
  dynamic feedback form from the same R316 model and explain why its timing
  changes the pole equation before opening a separate synthesis round.
- If pole-feasible candidates instead fail the governor, identify the exact
  node power, ramp, or SOC guard without relaxing any physical limit.
- Stop after one cause classification and one prospectively specified repair.
  Do not widen the observed scalar grid, run ANDES, design distributed agents,
  define rewards, or train a neural controller.
