## Why it matters

R65 W2 transfer of R64 combo (N_SUBSTEPS=3 / MAX_GRAD_NORM=0.5 /
batch_size=512 / lr=3e-3 clamped to 1e-4) to LSTM degrades 6-axis
3-seed mean from 0.432 (R57-α) to 0.327 (R65 W2) = **-24 %**.

lr=3e-3 is clamped to 1e-4 (CLM-0100) so LSTM effective lr unchanged
from R57-α. **The degradation comes from one or more of nsub=3, gc=0.5,
bs=512**. To know if any single axis is LSTM-friendly while others
are LSTM-hostile, need per-axis ablation.

If any axis benefits LSTM in isolation, R66+ could build LSTM-specific
combo. If all 3 axes are LSTM-hostile, R57-α combo is the only
production path and Q-0013 closes negative.

## Candidates

(cheapest first, all single-seed pilot s51)

- **nsub=3 only on LSTM** (~9 min): if better than R57-α 0.526, the
  ODE substep change is LSTM-positive.
- **gc=0.5 only on LSTM** (~9 min): if better than R57-α 0.526, the
  tighter gradient clip helps LSTM.
- **bs=512 only on LSTM** (~9 min): if better than R57-α 0.526,
  larger batch helps LSTM seq replay.

Total: ~30 min wall for full ablation pilot. If any axis wins,
expand to 3-seed.
