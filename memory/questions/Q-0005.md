## Why it matters

R56-α's 3-seed sweep produced a bimodal outcome:

- s49 6-axis 0.333, dM_span 122 % (converged, time-varying policy)
- s50 6-axis 0.109, dM_span 3 % (collapsed, near-static)
- s51 6-axis 0.526, dM_span 90 % (converged, **V4 SOTA**)

The s50 outcome blocks H1 (3-seed mean > 0.40): with s50's
0.109 included, mean = 0.3226; without it, mean = 0.4295. The
collapse correlates with a 15× initial critic-loss spike (8.155
vs 0.587 / 0.620 for s49 / s51), suggesting a value-bootstrap
explosion in the first ~10 episodes that pinned the LSTM into a
degenerate region of parameter space.

Resolving this question gates CLM-0064 (LSTM as production
recommendation). A 1/3 collapse rate is too high for a paper
headline; reducing it to ≤ 1/5 would let LSTM cleanly supersede
the R48-β/δ memoryless production triangle.

## Candidates

(cheapest first)

- **LSTM-specific lr warmup**: linear from 1e-5 → 1e-4 over the
  first 5 episodes, then constant. Standard recurrent-RL trick to
  stabilize early value-bootstrap. ~5 min implementation, 1× 3-seed
  rerun (~12 min).
- **Best-by-eval-score, not best-by-train-reward**: s50's saved
  `best.pt` is from ep 10 (pre-explosion), based on train reward.
  If we re-evaluate every saved-best candidate via the 6-axis
  ranker, we might find a later weakly-trained checkpoint that
  outperforms the pre-explosion one. ~10 min.
- **Gradient-clip lowering**: current max_norm=10 may be too
  permissive. Try max_norm=5 or 1 with the same seeds. ~5 min impl,
  ~12 min run.
- **Larger seed pool**: 5-seed sweep (49/50/51/52/53) to estimate
  the collapse rate (1/3 → 1/5 → 1/10). No code change, ~25-50 min
  wall (parallel-limited).
- **Longer training (200 ep)**: gives the LSTM more time to recover
  from a bad initialization. ~33 min/seed wall × 3 parallel = ~33 min.
- **Per-agent independent init**: currently all 4 agents share the
  same torch.manual_seed call. Try torch.manual_seed(seed*4 + i) so
  each agent has independent weights. ~3 min impl.
