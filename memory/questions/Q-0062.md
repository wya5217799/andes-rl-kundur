## Why it matters

The model-first manuscript cannot identify controller, information, or neural
architecture value until its executable plant matches the frozen equations.
The current legacy path mixes 50-Hz reporting with a 60-Hz plant, crosses
GENCLS device and system parameter bases during direct writes, exposes only a
partial ESD1 command/readback chain, uses an unweighted differential basis,
and has inconsistent active-power edge signs.  Any Stage-1 or training result
produced before those seams are repaired would be scientifically ambiguous.

## Candidates

- Add pure, public utilities for device-to-system GENCLS M/D conversion, the
  exact inertia-weighted common/differential transform and inverse, retained
  transformed blocks, and the frozen source-positive edge incidence.
- Add a separate model-first environment/configuration path that uses physical
  60 Hz, retains G4, disables the common Line_8 disturbance, and reports the
  requested, commanded, internal, and achieved actuator layers without
  changing V4.
- Add one deterministic no-disturbance Stage-0 adapter and report whose gates
  cover timing, DAE residual, actual M/D arrays, zero power layers, SOC drift,
  ESD1 internal limits/current, graph/index identity, and Line_8 status.
- Stop on the first invalid canary.  Stage 1, controller comparison, residual
  learning, and neural training require a later prospective authorization.
