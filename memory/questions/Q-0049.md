## Why it matters

R280 showed that learned differential allocation is useful in the frozen
scalar coordinate, but the tested parameter-shared branch centrally aggregates
four local votes into the same single action available to the centralized
actor. That experiment identifies one scalar factorization, not distributed
execution. The architecture question is therefore reopened only after changing
the identifiable control object from one scalar to a three-coordinate,
fleet-zero-sum vector residual.

## Candidates

- Matched centralized vector TD3: joint local measurements map directly to the
  three oriented edge-flow coordinates.
- Distributed edge TD3 under CTDE: one shared actor evaluates each declared
  communication edge from its two endpoint observations; each VSG executes the
  signed sum of incident edge flows without a centralized scalar aggregator.
- Frozen q=0 reference: the validated slow droop--PI storage layer plus the
  fixed 3 s common-inertia pulse and no differential residual.
- Not authorized: manuscript edits, topology variation, communication-delay or
  dropout claims, GNN expansion, reward/algorithm sweeps, HAWE, recurrent
  policies, EMT/HIL, stability certificates, or deployment claims.
