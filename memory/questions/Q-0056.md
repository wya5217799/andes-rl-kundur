## Why it matters

CLM-0700 establishes a strong explicit neighbour-local zero-sum classical
baseline. Neural training is justified only if a bounded edge-action library
first reveals material state-dependent headroom beyond the best fixed member,
and causal edge-local measurements carry information about that headroom.

## Candidates

- Keep the R298 controller, plant, vector active-power path and constraints
  fixed, then add one full-anchor increment either on all communication edges
  or on exactly one undirected ring edge.
- Use an outcome-seeing edge-library oracle only as an upper bound. Compare it
  with the best single fixed arm before considering an adaptive controller.
- Diagnose whether early pairwise frequency and filtered-RoCoF features rank
  the marginal value of the edge-local increments.

## Kill rules

- No material oracle margin over the best fixed arm closes adaptive learning
  on this edge-gain library.
- A single fixed arm explaining the apparent gain redirects work to classical
  retuning, not neural training.
- Outcome-only headroom without a causal local-information signal does not
  authorize distributed-network training.
- A positive development signal authorizes only a deployable causal candidate;
  performance requires a later sealed evaluation on the predeclared disjoint
  bank.
