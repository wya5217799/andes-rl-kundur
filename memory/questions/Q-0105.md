## Why it matters

R384 stopped a construction that left four status-zero `GENROU`, `TGOV1`, and
`EXDC2` chains in the initialized DAE. Installed ANDES source shows that some
internal block equations are not status-gated, so that result cannot separate
the candidate `REGCV1` object from the retained legacy equations. One
structurally clean successor is the cheapest decisive test before abandoning
`REGCV1` or changing platform, topology, parameters, or controller.

## Prospective contract

- Use ANDES 2.0.0 and exact static tables from the packaged Kundur XLSX/JSON;
  preserve all bus, load, generator, line, area, rating, setpoint, and
  connectivity values.
- Generate a deterministic static-only case containing only
  `Bus/PQ/PV/Slack/Line/Area`, then add exactly four `REGCV1` devices with the
  R384 parameter card and mapping `(REGCV1_1,1,1)` through
  `(REGCV1_4,4,4)`.
- Require zero `GENROU`, `TGOV1`, `EXDC2`, and `Toggler` devices and no legacy
  DAE equation names. Status-zero records do not satisfy this condition.
- Run one sealed zero-input, no-controller, no-training job through setup,
  power flow, native TDS initialization, and 0.2 seconds of TDS. Serialize
  every nonzero/NaN initialization residual and clamped-limit row.
- Compare post-init `Pref/Qref` against the frozen static-generator `p/q` with
  absolute tolerance `1e-12`, and require finite DAE/REGCV1 values plus
  native-tolerance zero-input drift.
- PASS opens only a separately registered signed dynamic authority gate. A
  valid scientific failure stops `REGCV1`; an integrity failure is invalid and
  permits no in-round retry.
