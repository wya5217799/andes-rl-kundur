## Why it matters

R323 finds no checked unit, base, sign, frequency, or charging-path
contradiction and blocks direct attribution of R321/R322 to ANDES because those
rounds did not execute it. It also identifies two unresolved upstream limits:
the physical provenance of project-selected GENCLS-proxy, ESD1, and execution-
layer parameters, and numerical convergence of the fastest represented plant
dynamics. Q-0078 must not synthesize another controller against an object whose
parameter meaning or time resolution may still change.

## Candidates

- Build one line-scoped parameter table covering value/unit, device or system
  base, source, represented physical object, and status as measured,
  literature-derived, manufacturer-derived, identified, or explicit modelling
  assumption. Prioritize proxy inertia/damping, storage power/energy,
  active-current time constant, efficiency, SOC bounds, external ramp, and
  control period.
- Freeze one unchanged operating point, the existing small signed open-loop
  active-power pulse, integration method, endpoint definitions, step-size
  sequence, tolerances, and invalidation rule before executing a physical
  trajectory. Compare achieved power, selected frequency outputs, SOC, peak
  timing, and terminal state across adjacent refinements.
- Use no controller, holdout, reward, distributed runtime, agent, training, or
  post-outcome parameter repair. EVAL is not applicable to this open-loop
  convergence estimand; retain it for a later sealed closed-loop physical round
  as a post-score diagnostic only.
- If all material values have a defensible source or are explicitly bounded as
  modelling assumptions and adjacent refinements meet the frozen tolerance,
  return to Q-0078 on the unchanged plant. If not, stop controller work, version
  the plant/integration contract, and revalidate physical data plus the reduced
  model before using any downstream controller result.
