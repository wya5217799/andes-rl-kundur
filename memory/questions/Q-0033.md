## Why it matters

R270 provides a clean modal separation.  A disturbance-informed library oracle
using the current M/D inputs materially improved synchronization loss, RoCoF,
and peak deviation, yet changed VSG-mean IAE by only 0.311%.  This suggests the
current actuator is useful for fast transient shaping but is a weak mechanism
for common-frequency restoration.

Adding another neural network cannot answer whether this limitation is
structural.  The next step is to inspect the implemented swing, storage-power,
governor, and action equations and test existing terminal behavior before
changing the model.  Only if an explicit active-power or secondary-frequency
input is physically required should the project expand to a multi-timescale
actuator architecture.

## Pre-commitment for the future round

1. Begin with a source/equilibrium audit of the current VSG `M`, `D`, `P_es`,
   governor, disturbance, and steady-state equations; use physical 60-Hz
   units and document which inputs disappear or remain at equilibrium.
2. Reuse R268 and R270 trajectories to compare early versus terminal common
   frequency response for common M and D directions.  Run no new ANDES and
   make no environment change until the structural hypothesis is explicit.
3. Distinguish three claims: transient RoCoF shaping, oscillation damping, and
   sustained/common frequency restoration.  Do not infer one from another.
4. If a new actuator is necessary, specify its power/energy limits, state,
   timescale, and classical baseline before implementation.  Do not add a
   generic unconstrained action channel just to improve a metric.
5. Keep neural training, topology generalization, stability certification,
   cross-simulator work, and manuscript production out of the actuator audit.

## Decision direction

- If equations and existing trajectories show that M/D-only control cannot
  provide material common-mode restoration under the present model, retain
  M/D only as a fast safety layer and propose one physically constrained
  active-power/secondary-control contract for a future feasibility pilot.
- If D or another existing channel has adequate equilibrium authority but the
  R270 library failed to access it, identify the exact observability/timescale
  mechanism before any further experiment; do not reopen broad searches.
- If the model's actuator semantics are not credible for the intended VSG
  research question, pivot to model/benchmark correction before control.
