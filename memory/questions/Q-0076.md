## Why it matters

R320 establishes only that one exact pole template is mathematically placeable
on all four delayed reduced-model pairs. It does not establish finite gain
quality, constrained disturbance rejection, estimation behavior, mismatch
tolerance, or incremental retained-cross value. Those gates must pass before
any physical deterministic controller question can be opened.

## Candidates

- Recompute the exact R320 controller and corrected-observer templates with the
  same targets, placement method, tolerance, and one-call budget. No pole,
  target, gain, covariance, or scalar search is allowed.
- Preserve the R319 full retained-cross executed plants, output/action scales,
  delayed four-coordinate information, known point scheduling, node mapping,
  power/ramp/SOC limits, initial estimates, and matched cross-deleted synthesis
  model. Add no actuator authority or centralized information.
- Run the unchanged 32-case development bank. Only if both arms pass nominal
  poles, finite gain/estimate/output/action, and governed constraints, access
  the still-untouched 80-case bipolar/mismatch examination.
- Require the retained arm's every-case two-percent absolute improvement and
  two-percent mean and worst matched improvements. Stop at PASS, NO-GO, or
  invalid; do not run ANDES, implement distributed agents, define rewards, or
  train a neural controller.
