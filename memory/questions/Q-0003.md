## Why it matters

R41-B established TD3 + V4Config normalized as the production
single-seed configuration (mean 0.275, range [0.267, 0.280]). HAWE
w9802 (CLM-0007) reached 0.439 by ensembling lucky SAC checkpoints
at inference time. The natural question: does the HAWE recipe still
deliver an uplift when the input actors are reliably-trained TD3
normalized (small inter-seed std, presumably less complementary)
rather than lucky SAC? If yes, ensembling is essentially free on
top of CLM-0047. If no, the R34 HAWE win was specific to SAC entropy
noise.

## Candidates

- **Weighted ensemble (0.33/0.34/0.33), --agg weighted**: matches
  HAWE w9802 recipe — uniform-ish weights. Cheapest (~30s eval).
- **Mean / median / optimized-weight sweep**: defer to a follow-up
  round if the uniform-weighted run is interesting.
