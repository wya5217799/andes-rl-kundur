## Why it matters

CLM-0174 quantified the actor's LSTM warm-up: ||a||_step0 = 0.149 (10%
of max), reaches saturation by step 10. CLM-0170 (R92) identified
action-space saturation as plateau mechanism #1; CLM-0174 identifies
LSTM warm-up lag as plateau mechanism #2. R94 (in flight) tests
widening action bounds, which addresses mechanism #1 but **not** #2.

If R94 falls into Outcome B (widen-bound caps near 0.391, CLM-0175),
then actor-architecture fix is mandatory. The cheapest single-knob
candidate: **learn an h_0 initialiser** mapping initial obs to the
LSTM hidden state, so step 0 actor output is closer to its
asymptotic value.

Falsifies if: training with warm h_0 still produces 10-step ramp
(LSTM internal dynamics dominate over h_0). Confirms if: step 0
||a|| reaches 0.7+ AND geo > R72_w4 baseline + 5%.

Cheaper than full architecture redesign; one parameter group
(MLP from obs_dim to h_dim) added; loss unchanged. 1 file diff
in `src/andes_rl_kundur/agents/networks.py` (RecurrentActor.__init__
adds `self.h_init = nn.Sequential(...)`; `forward` initial step uses
h_init(obs_0) instead of zeros).

## Candidates

- (cheapest) Tiny MLP init: `h_0 = MLP(obs_0)`, 1 hidden layer
  of 32 units, tanh activation, output dim = hidden_size of LSTM.
  Frozen action[1] bias = +0.985 (steady-state value) for tanh.
- (medium) Learn both h_0 and c_0 (cell state) via MLP.
- (more expensive) Residual feedforward action path: `a =
  tanh(LSTM(obs, h) + W_skip @ obs)`. h-free shortcut for emergencies.
