## Why it matters

R86 CLM-0155 found 6/6 ckpts (SAC, TD3, TD3-LSTM × multiple seeds) all
collapse to monotone-in-action Q + boundary argmax on prior obs.
CLM-0157 declared R87+ priority should be critic-representation
perturbation, not algo-class sweep. The single highest-leverage candidate
is a distributional critic head: instead of point-estimate Q(s, a),
predict a distribution over returns (IQN: quantile regression of returns
at uniformly-sampled τ ∈ [0,1]). Theoretical hope: distributional
target signal is richer than scalar TD error, breaks "regress all
actions to mean" collapse, may force critic to learn concave action
preference.

If TRUE (distributional critic monotone_fraction << 0.5, advantage > 0,
argmax_dist < 0.5): R86 mechanism layer **and** R87 fix in one round.
Paper narrative cleanest possible.

If FALSE: monotone-Q pathology survives distributional head — points
to action-space-side fix (CLM-0157 candidate (b) feature engineering)
or env-side fix (R83 obs-space, if successful).

## Candidates

- (cheapest) Implement IQN-style quantile head on existing td3_lstm
  critic (single layer change: output 32-quantile vector instead of
  scalar Q; train with quantile Huber loss). 1 seed × 75 ep on Kundur
  V4 baseline, then re-run R86 forensics on the resulting ckpt.
- (more expensive) QR-DQN (deterministic quantiles, no τ sampling).
- (most expensive) Implicit ensemble of N critics with deep diversity
  regularisation.
