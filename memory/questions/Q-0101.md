## Why it matters

The fixed manuscript title requires `Paralleled VSGs`, `Coordination`, and
`MARL` to refer to the same runtime object.  The legacy V4 implementation
appears to expose four actors and two actions per actor, but that availability
is not evidence that the device mapping, information timing, differential
dynamics, and physical authority are valid on the new title-goal line.  A
learner would only repeat the old object-mismatch failure if any one of those
premises is false.

## Prospective contract

- Use the existing V4 plant through its public constructor, `reset`, `step`,
  observation, and `info` seams without changing protected environment code.
- Fix one six-second load-step experiment, no communication failure or delay,
  no legacy line-trip event, no checkpoint, no policy, and no reward-based
  endpoint.
- Compare two repeated homogeneous zero-action traces, four one-agent
  interventions, one distinct eight-coordinate action fingerprint, and one
  heterogeneous damping mismatch under the same disturbance.
- Infer numerical floors only from the two repeated zero-action traces.  PASS
  requires all five gates in `paper/paralleled_vsg_marl/ROUTE.md#first-experiment`:
  four unique device identities, independent M/D readback, exact same-instant
  local-neighbour observations, differential dynamics above the frozen noise
  floors, and bounded nonzero plant authority without a TDS failure.
- Any failed gate returns a typed STOP for this registered V4 formulation.
  It does not reject other plants, direct MARL, residual MARL, or MARL as a
  class.  PASS authorizes only the next deterministic-baseline/headroom gate;
  neural-network training remains prohibited.
