### 方向 0（根因澄清）：平台 2× 残差的真正来源

这是最重要的发现。Kundur 标准系统的 H 值：Area 1 每台机 H=6.5 s，Area 2 每台机 H=6.175 s，4台同步机总有效惯量约 25.35 s（系统基准 2200 MVA）。

对 LS1（248 MW = 0.113 pu）作 ROCOF 估算：`max_df ≈ ΔP / (2 × H_eff × f_nom) ≈ 0.113 / (2 × 6.35 × 50) × 0.7s ≈ 0.12 Hz`，与 paper 的 0.13 Hz **完全吻合**。

这意味着 paper 用的是 **标准 Kundur H=6.5/6.175 s 同步机 + governor + AVR 全激活**，而你的 ANDES V2 env 没有 governor，所以：

| 配置 | no_ctrl max_df | 理由 |
|---|---|---|
| Paper Simulink（SG + Gov + AVR） | 0.13 Hz | 标准 Kundur H + governor damping |
| ANDES V2（SG, 无 Gov） | 0.815 Hz | 无 governor damping |
| ANDES H=300（大量 ESS 虚拟惯量） | 0.266 Hz | ESS H 拉大，但仍无 governor |

**结论：Root #3「平台 2× 残差」的主因不是 solver 差异，而是 governor 未连通。修好 governor = 消除大部分残差。**

ANDES 官方已在 WECC 179-bus case 中验证 GENROU + IEEEG1 + EXST1 + ESST3A 全部正常工作，与 PSS/E 和 DSATools TSAT 结果吻合。说明 IEEEG1 模型本身没问题，是你的接线方式有误。

排查方向：
- ANDES `IEEEG1` 的 `syn` 字段必须指向 `GENROU` 的 **idx**（不是 uid 或其他）
- `Pgv`（governor 输出）→ `GENROU.Pm`（机械功率输入）在 ANDES 里是通过 `TurbineGov` → `SynGen` 自动 wire，触发条件是 `syn=GENROU_idx` 正确写入

ANDES 官方论文中展示了 TGOV1 在 Kundur 系统的完整验证，证实了 TDS 与 DSATools 高度吻合。用 TGOV1（更简单的 governor）替代 IEEEG1 先做验证是更稳妥的起点。

### 方向 2：Physics-Informed RL 加速训练收敛

找到最直接相关的论文：**PI-AC（Physics-Informed Actor-Critic）**，专门针对虚拟惯量协调场景。

PI-AC 算法将电力系统摆动方程的物理行为整合到 Actor-Critic 方法中，通过在损失函数中加入聚合功率系统动力学模型的正则化项，在 CIGRE 14-bus 和 IEEE 37-bus 系统上实现了比纯数据驱动 AC 和遗传算法更快的学习速度和更高的奖励。

**实现方案（对你的项目）：** 在 SAC 的 Critic 损失上加一项 swing equation 残差惩罚：

```
J_physics = ||H·Δω̇ + D·Δω - (Δu - ΔP)||²
```

这让 critic 的 Q 值估计被物理模型约束，减少探索所需的样本数。论文 Section II-A 的 Eq.1 就是这个 swing equation，天然可用作物理正则项。目标是把 500 episode 稳定收敛提前到 ~150-200 episode。

### 方向 3：升级到 CTDE 架构（集中训练、分散执行）

Yang2023 用的是 fully distributed（每 agent 只看邻居），这是为了可扩展性。但在 4-agent 固定拓扑的 KD 实验里，CTDE 提供直接提升空间。

主流 CTDE 框架中，critic 获取全局观测和动作信息来评估各个 agent 的动作对全局的影响，从而引导 actor 更新策略以提升全局收益；但该框架在 agent 数增多时可扩展性差。

对你的场景：4 agent 固定 → CTDE critic 输入维度 = 4×7 obs + 4×2 action = 36，完全可行。训练时用全局 critic，执行时每个 VSG 仍只用局部观测的 actor，满足 paper 的分散控制要求。预期改善：更稳定的 critic 估计 → 减少 attractor 问题。

### 方向 4：奖励函数改进——加入 settling-time 项

Lu & Zhuan 2024 在 VSG SAC 控制中将 setting-time 项加入奖励函数设计（与功率和频率偏差并列），以避免因过度优化导致系统长时间暂态的问题。

Yang2023 的 `r^f`（Eq.15）只惩罚节点间**频率差**（同步度），不惩罚**频率绝对偏差**（恢复度）。这在训练上正确（频率恢复是 governor 的工作），但在你的场景下：governor 修好后，如果 SAC 与 governor 之间出现控制冲突（SAC 拉大惯量 vs governor 试图恢复频率），需要一个协调项。加 settling-time 惩罚可以引导 SAC 不要「拖慢」governor 的恢复。

---

### 方向 5：ROCOF/Nadir 分析验证 paper 数字真实性

考虑不同额定容量机器的系统响应阶跃扰动时，频率的 Nadir 和 RoCoF 可分别由系统频率的 L∞ 范数及其导数来表征；系统惯量在经典摆动动力学模型中对性能的作用比传统认知更复杂，只有在引入汽轮机动力学后，惯量的收益才变得更加显著。

这直接解释了为什么 H=300 的 ESS（纯虚拟惯量，无 turbine governor 动力学）在 ANDES 中效果没有 paper 中那么好——paper 的同步机有完整的 governor dynamics，而 ESS 的虚拟惯量没有二次频率恢复能力。
