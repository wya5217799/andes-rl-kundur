实验汇报术语翻译卡

不要先背定义。先判断这个词在故事中扮演什么角色。

术语自然中文在实验里的角色
HP1 / HQ0 / HQ1几个工况的代号，类似试卷 A、B、C场景标签，本身没有物理结论
operating condition电网开始实验时所处的具体状态实验条件
development data允许研究者看答案、用来改模型的资料学习资料
holdout改模型时不许偷看的新考题正式考试
freeze考试前把方法和门槛锁死防止看成绩改规则
local simplex用附近几个已知工况按固定权重拼出新工况的预测预测方法
predictor给定扰动后，预先估计系统会怎样响应的简化模型被考试的对象
ANDES trajectory仿真器跑一次后得到的一整段时间变化记录物理仿真记录
EVAL view从已有仿真记录整理出的审计视图检查材料，不是又跑一次物理实验
NRMSE把整体预测偏差缩放后得到的误差分数；越小越好判卷分数
cross output动了一个坐标，却在另一个坐标上也出现的响应被保留的耦合信息
ablation只拿掉一个成分，再与完整方法公平比较判断该成分是否有用
dynamic mismatch简化动态模型与真实仿真动态之间还可能出现的差距下一道尚未通过的门

固定翻译顺序

旧问题 → 哪些资料可以学习 → 方法怎样锁定 → 用什么新题考试 → 成绩如何 → 只允许得出什么。
